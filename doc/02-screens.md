# 2. 화면별 사용법

앱은 9개 화면으로 이루어져 있습니다.

| 화면 | 경로 | 역할 |
| --- | --- | --- |
| 홈 | `/` | 플랜 목록, 기획하기 위저드, 가져오기 |
| 개요 | `/plans/{id}` | 파이프라인, 정합성 검사, 버전, 코멘트 |
| 프로덕트 요구사항 | `/plans/{id}/prd` | 제품 정의 문서 |
| 기능명세서 | `/plans/{id}/fs` | 요구사항 → 기능 → 상세명세 |
| 정보구조도 | `/plans/{id}/ia` | 화면 계층과 기능 배치 |
| 유저 플로우 | `/plans/{id}/flow` | 화면을 오가는 경로 |
| 와이어프레임 | `/plans/{id}/wireframe` | 화면별 블록 구성 |
| 내보내기 | `/plans/{id}/export` | 파일·이미지·링크로 전달 |
| 공유(보기 전용) | `/share#...` | 링크로 받은 문서를 읽기만 |

## 공통 요소

### 워크스페이스 헤더

플랜에 들어가면 상단에 항상 보입니다.

| 요소 | 설명 |
| --- | --- |
| 로고 + `<` | 누르면 플랜 목록으로 나갑니다 |
| 플랜 이름 | 현재 편집 중인 플랜 |
| `200 / 200 (임시)` | 남은 크레딧 / 하루 한도. (임시)는 정식 요금제 전 임시 한도라는 표시 |
| `AI 에이전트` | 우측 대화 패널을 엽니다 |

### 좌측 사이드바

7개 메뉴가 파이프라인 순서대로 있습니다. 각 산출물 옆의 점은 생성 여부입니다.

- 초록 점 — 생성 완료
- 회색 점 — 아직 만들지 않음

모바일에서는 화면 하단 탭으로 바뀝니다.

### 자동 저장

모든 편집은 입력칸에서 포커스가 빠질 때 자동 저장됩니다. 저장 버튼은 없습니다.
데이터는 브라우저 localStorage 에 보관됩니다.

### AI 에이전트 패널

우측 패널에서 현재 플랜 전체를 읽고 답하거나, 요청대로 문서를 고칩니다.

- **대상 항목 선택** — 드롭다운에서 특정 요구사항·기능·화면을 고르면 입력창 위에 표시되고,
  그 항목을 기준으로 답합니다.
- **⌘/Ctrl + Enter** 로 전송합니다.
- 메시지당 1 크레딧이 차감되고, 크레딧이 없으면 입력창이 비활성화됩니다.
- 문서를 수정했다면 답변 아래에 "문서 반영됨" 과 변경 목록이 표시됩니다.

## 홈 `/`

### 상단

- 로고와 서비스명
- `AI 생성` 칩 — API 키가 설정돼 AI 가 산출물을 만드는 상태
- `내장 생성기` 칩 — 키가 없어 규칙 기반으로 만드는 상태 (안내 배너도 함께 표시)
- `크레딧 200/200 (임시)`

### 버튼

| 버튼 | 동작 |
| --- | --- |
| ＋ 기획하기 | 3단계 위저드를 엽니다 |
| 플랜 가져오기 | 내보낸 플랜 JSON 파일을 불러옵니다 (여러 개 동시 가능) |

JSON 파일을 화면에 **끌어다 놓아도** 가져오기가 됩니다.

### 플랜 카드

카드마다 서비스명, 한 줄 소개, 플랫폼, 산출물 5종 진행 상태, 항목 수, 최종 수정 시각이 있습니다.
카드를 누르면 그 플랜으로 들어갑니다.

우측 상단 **⋮** 메뉴:

| 항목 | 동작 |
| --- | --- |
| 이름 변경 | 서비스명을 바꿉니다 |
| 복제 | 같은 내용의 플랜을 하나 더 만듭니다 |
| JSON 내보내기 | 플랜 전체를 파일로 저장합니다 |
| 삭제 | 확인 후 완전히 지웁니다 (되돌릴 수 없음) |

## 개요 `/plans/{id}`

### 상단 요약

서비스명을 눌러 바로 수정할 수 있습니다. `브리프 보기` 를 펼치면 위저드에서 입력한
아이디어·참고 서비스·필수 기능이 나옵니다.

### 산출물 파이프라인

5개 스텝 카드가 순서대로 있습니다. 각 카드에는 생성 여부, 항목 수, 소모 크레딧이 표시됩니다.

| 버튼 | 동작 |
| --- | --- |
| 전체 자동 생성 | PRD → 기능명세서 → 정보구조도 → 유저 플로우 → 와이어프레임을 순서대로 실행합니다. 중간에 실패하면 멈추고 알려 줍니다 |
| AI로 생성 / 다시 생성 | 그 단계만 생성합니다. 이미 있으면 확인 후 덮어씁니다 |
| 열기 | 해당 산출물 화면으로 이동합니다 |

앞 단계가 없으면 버튼이 비활성화되고 이유가 표시됩니다.
예) 정보구조도는 기능명세서가 있어야 만들 수 있습니다.

### 정합성 검사

산출물끼리 연결이 끊긴 곳을 자동으로 찾습니다.

| 등급 | 뜻 |
| --- | --- |
| 오류 | 참조가 깨져 문서가 성립하지 않는 상태 |
| 경고 | 논리적으로 빠진 부분. 개발 착수 전에 채워야 함 |
| 제안 | 있으면 좋은 보완 사항 |

검사 항목 예시:

- 어느 화면에도 배치되지 않은 기능
- 하위 기능이 없는 요구사항
- 상세 명세가 없는 필수(P0) 기능
- 인수 조건이 없는 상세 명세
- 도달할 수 없는 플로우 단계 / 빠져나갈 수 없는 단계
- 분기가 하나뿐인 조건 (실패·거절 경로 누락 가능성)
- 경로가 중복된 페이지
- 대상 화면이 사라진 와이어프레임

각 항목에서 해당 산출물로 바로 이동할 수 있습니다.

### 버전 기록

큰 수정 전에 **[현재 상태 저장]** 으로 스냅샷을 남겨 두면 나중에 되돌릴 수 있습니다.
최근 20개까지 보관합니다. 복원은 확인을 거칩니다.

### 코멘트

미해결 코멘트 수와 최근 5건을 보여줍니다. 여기서 새 코멘트를 남기거나 해결 처리할 수 있습니다.

## 프로덕트 요구사항 `/prd`

제품이 무엇이고 누구를 위한 것인지 정의하는 문서입니다. 이후 모든 산출물의 기준이 됩니다.

### 상단 툴바

| 버튼 | 동작 |
| --- | --- |
| 문서 보기 / 편집 | 읽기 좋은 발표용 레이아웃과 편집 폼을 오갑니다 |
| AI로 생성 / 다시 생성 | PRD 를 생성합니다 |
| 다음 단계로 → | 기능명세서로 이동합니다 |

그 아래 목차 칩을 누르면 해당 섹션으로 스크롤합니다.

### 10개 섹션

| # | 섹션 | 내용 |
| --- | --- | --- |
| 1 | 제품 개요 | 이 제품이 무엇이고 누구에게 어떤 가치를 주는지 |
| 2 | 배경 및 문제 정의 | 왜 지금 이 제품이 필요한지 |
| 3 | 핵심 목표 | 목표와 판단 지표를 짝지어 작성. 순서 이동 가능 |
| 4 | 타겟 유저 | 페르소나별 이름·소개·니즈·페인포인트 |
| 5 | 사용자 역할 | 역할명·설명·권한. **정보구조도의 접근 역할 선택지가 됩니다** |
| 6 | 사용 환경 | 지원 플랫폼·기기·브라우저 |
| 7 | 핵심 가치 | 이 제품이 지키려는 가치 |
| 8 | 성공 지표 | 지표명과 목표 수치 |
| 9 | 범위 | 포함 / 제외를 나란히. 제외 항목은 흐리게 표시 |
| 10 | 제약사항 | 일정·인력·정책 제약 |

각 섹션 헤더의 말풍선 아이콘으로 그 섹션에 코멘트를 남길 수 있습니다.

## 기능명세서 `/fs`

**요구사항(REQ) → 기능(FN) → 상세명세(SP)** 3단 구조입니다.

- **요구사항** — 무엇이 필요한가
- **기능** — 그것을 어떤 기능으로 푸는가
- **상세명세** — 그 기능이 화면에서 어떻게 동작하는가

### 상단 툴바

요약 칩(요구사항 n · 기능 n · 상세명세 n · 필수 n), 검색, 우선순위 필터, 상태 필터,
`마인드맵` / `리스트` / `표` 보기 전환, `AI로 생성`, `다음 단계로`.

### 세 가지 보기

같은 데이터를 세 방식으로 봅니다. 어느 보기에서 고치든 곧바로 나머지에 반영됩니다.
검색·필터도 세 보기에 똑같이 적용됩니다.

| 보기 | 언제 쓰나 |
| --- | --- |
| **마인드맵** (기본) | 전체 구조를 한눈에 보고 빠진 곳을 찾을 때 |
| **리스트** | 한 요구사항을 파고들며 차근차근 채울 때 |
| **표** | 우선순위·상태를 한 번에 훑고 고칠 때 |

### 마인드맵 보기 (기본)

`PRD → 요구사항 → 기능 → 상세명세` 네 단계를 왼쪽부터 가로로 펼칩니다.

- 요구사항마다 색이 다르고, 그 아래 기능·상세명세가 같은 색을 물려받습니다.
- 오른쪽 끝 번호(`1.1.2`)는 요구사항·기능·상세명세 순서입니다.
- 노드 앞의 점은 작업 상태입니다. (회색 작성전 · 주황 작성중 · 파랑 검토중 · 초록 확정)
- 노드를 누르면 **오른쪽에 편집 패널**이 열립니다. `닫기`로 접으면 캔버스가 넓어집니다.
- 비어 있는 자리의 **`핵심 기능 추가` · `상세 기능 추가`** 를 누르면 그 자리에 바로 만들어집니다.
- 맨 왼쪽 `PRD` 를 누르면 프로덕트 요구사항 화면으로 이동합니다.
- 우측 상단 `-` `100%` `+` 로 배율을 조절합니다. 캔버스는 스크롤됩니다.

### 리스트 보기

3단 컬럼입니다.

| 열 | 내용 |
| --- | --- |
| 1열 `요구사항` | 번호·제목·우선순위·하위 기능 수. 고르면 2열이 바뀝니다 |
| 2열 `기능 / 상세 기능` | 고른 요구사항의 기능 목록. `›` 로 펼치면 상세명세가 나옵니다 |
| 3열 | 선택한 항목의 편집 패널 |

각 열 오른쪽 위 `+` 로 요구사항·기능을 추가합니다.

### 편집 패널

세 보기가 같은 패널을 씁니다.

**요구사항 편집** — 제목, 설명, 분류, 우선순위, 삭제
(삭제하면 하위 기능과 상세명세도 함께 지워집니다)

**기능 편집** — 기능명, 설명, 우선순위, 상태, 상위 요구사항 변경
+ 이 기능이 배치된 화면 목록(읽기 전용)
+ **연결된 상세 기능** — 하위 명세를 카드로 보여 줍니다. 카드를 누르면 그 명세로 넘어갑니다

**상세명세 편집**

| 항목 | 설명 |
| --- | --- |
| 수행 주체 | 누가 하는 동작인지 |
| 사전 조건 | 이 동작이 가능한 상태 |
| 기본 흐름 | 사용자와 시스템의 행동을 번갈아 적습니다 |
| 예외 처리 | 오류·권한 없음·네트워크 실패 등 |
| 인수 조건 | QA 가 그대로 테스트할 수 있는 문장으로 |
| 연결 화면 | 정보구조도의 페이지를 다중 선택 |

### 표 보기

요구사항과 기능을 한 테이블로 펼칩니다. 우선순위와 상태는 표에서 바로 바꿀 수 있습니다.
기능 ID 를 누르면 리스트 보기로 전환되며 그 항목이 펼쳐진 채 선택됩니다.

### 우선순위

| 값 | 표시 | 뜻 |
| --- | --- | --- |
| P0 | 필수 | 없으면 출시 불가 |
| P1 | 높음 | 1차 범위 |
| P2 | 보통 | 여유가 되면 |
| P3 | 낮음 | 나중에 |

## 정보구조도 `/ia`

서비스의 모든 화면을 계층으로 정리하고, 각 화면에 기능을 연결합니다.

### 보기 3종

| 보기 | 쓰임 |
| --- | --- |
| 트리 | 계층 구조를 보며 편집. 기본 보기 |
| 표 | Depth·경로·역할·연결 기능을 한눈에. 엑셀로 옮기기 좋음 |
| 사이트맵 | 1depth 를 열로 두고 하위를 쌓아 전체 그림을 봄 |

### 트리 보기에서 할 수 있는 것

각 행에서 페이지명과 경로를 바로 수정하고, 유형(페이지·모달·탭·섹션)을 바꿉니다.

| 아이콘 | 동작 |
| --- | --- |
| ＋ | 하위 페이지 추가 |
| ↑ ↓ | 같은 depth 안에서 순서 이동 |
| 상세 토글 | 설명·접근 역할·기능 연결을 펼침 |
| 🗑 | 삭제 (하위 페이지도 함께 삭제) |

**상세 패널**에서:

- **설명** — 이 화면이 무엇을 하는지
- **접근 역할** — PRD 의 사용자 역할 중에서 고릅니다
- **상세 기능 연결** — 요구사항별로 묶인 기능 목록에서 체크합니다.
  이미 다른 화면에 배치된 기능은 그 화면 이름이 함께 표시됩니다.

### 미배치 기능 경고

어떤 화면에도 연결되지 않은 기능이 있으면 상단에 경고 배너가 뜹니다.
누르면 목록을 볼 수 있습니다. **이 연결이 정합성 검사와 와이어프레임 생성의 기준이 됩니다.**

## 유저 플로우 `/flow`

사용자가 화면을 오가는 경로를 그립니다.

### 노드 종류

| 종류 | 모양 | 쓰임 |
| --- | --- | --- |
| 시작 | 둥근 알약 | 진입점 |
| 화면 | 상단 강조 바가 있는 사각형 | IA 페이지에 연결 |
| 사용자 행동 | 사각형 | 클릭·입력 등 |
| 분기 | 마름모 | 조건에 따라 갈림 |
| 시스템 처리 | 평행사변형 | 저장·발송 등 |
| 종료 | 둥근 알약 | 흐름의 끝 |

### 편집

- 상단 탭으로 플로우를 전환합니다.
- 플로우명·수행 역할·설명을 바로 수정합니다.
- 캔버스에서 노드를 누르면 우측에 편집 패널이 열립니다.
- 노드 편집에서 **연결 화면**을 지정하면 IA 페이지와 이어집니다.
- 연결선 목록에서 출발/도착 노드와 조건 라벨을 바꿀 수 있습니다.

### 점검 배너

이 화면 상단에는 플로우 관련 정합성 문제만 모아 보여줍니다.
도달할 수 없는 단계, 빠져나갈 수 없는 단계, 분기가 하나뿐인 조건 등입니다.

## 공유(보기 전용) `/share#...`

내보내기에서 만든 링크로 접속하면 나오는 화면입니다.

- 문서 전체를 읽기 좋은 형태로 보여주며 **수정은 불가능합니다.**
- 문서 내용은 링크의 `#` 뒷부분에 담겨 있고, 이 부분은 **서버로 전송되지 않습니다.**
- 인쇄 버튼으로 PDF 저장이 가능합니다.
