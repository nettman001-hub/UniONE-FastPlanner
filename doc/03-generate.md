# 3. AI로 만들기

## 개요 화면

기획서에 들어가면 처음 보이는 화면입니다. 여기서 문서를 만들고, 상태를 확인합니다.

| 구역 | 하는 일 |
| --- | --- |
| **맨 위** | 서비스명(눌러서 바로 수정) · `브리프 보기`로 처음 입력한 내용 확인 |
| **산출물 파이프라인** | 다섯 문서를 만드는 곳 |
| **정합성 검사** | 문서끼리 안 맞는 곳을 찾아 줍니다 |
| **버전 기록** | 되돌릴 지점을 저장해 둡니다 |
| **코멘트** | 메모를 남깁니다 |

---

## 전체 자동 생성 — 한 번에 다 만들기

**`전체 자동 생성`** 을 누르면 다섯 문서를 순서대로 만듭니다.

```
프로덕트 요구사항 → 기능명세서 → 정보구조도 → 유저 플로우 → 와이어프레임
```

**순서가 정해져 있는 이유**가 있습니다. 앞 문서를 재료로 뒷 문서를 만들기 때문입니다.
기능명세서가 있어야 그 기능들을 어느 화면에 넣을지 정할 수 있고, 화면이 정해져야
화면을 오가는 흐름을 그릴 수 있습니다.

### 만드는 동안

- **다른 메뉴로 옮겨 다녀도 됩니다.** 계속 만들어집니다. 왼쪽 메뉴에서 어느 단계를
  만들고 있는지 돌아가는 표시로 보여 줍니다.
- 만들어진 문서는 **끝나는 대로 하나씩** 화면에 채워집니다. 다 끝날 때까지 기다릴 필요가 없습니다.
- 생성 중인 버튼은 **진한 색에 `생성중`** 으로 바뀝니다. 고장 난 것이 아니라 일하는 중입니다.

### 우리 회사 양식대로 만들게 하려면 — 기획 스킬

**설정 → 기획 스킬**에 단계마다 지킬 것을 적어 두면, 만들 때마다 그 결을 따릅니다.
한 번 적어 두면 이 계정으로 만드는 모든 플랜에 적용됩니다.

> ## 우리 용어
> - 서비스를 쓰는 사람은 '회원' 입니다. '유저', '고객' 은 쓰지 않습니다.
>
> ## 문체
> - 요구사항은 '~해야 한다' 로 끝냅니다.

무엇을 적어야 할지 모르시겠으면 **`예시 넣기`** 를 누르세요. 단계마다 예시가 채워지니
그걸 고쳐 쓰시면 됩니다. 적어 둔 `.md` 파일이 있으면 **`파일에서`** 로 올리셔도 됩니다.

**바꿀 수 있는 것은 내용과 문체입니다. 문서의 구조는 바꿀 수 없습니다.**

| ✅ 되는 것 | ❌ 안 되는 것 |
| --- | --- |
| "요구사항은 `~해야 한다`로 끝낸다" | "PRD에 리스크 항목을 추가한다" |
| "우리 용어(회원/운영자)를 쓴다" | "우선순위를 다섯 단계로" |
| "오류 상황을 반드시 하나씩 넣는다" | "기능명세서에 담당자 열을 넣는다" |

오른쪽은 **담을 자리가 없어서** 안 됩니다.

> 지침이 길수록 정작 문서에 쓸 여유가 줄어듭니다. 꼭 지켜야 할 것만 적으세요.
> 단계마다 4,000자까지입니다.

잠깐 꺼 두고 싶으시면 **`켜기`** 체크를 풀면 됩니다. 지우지 않아도 됩니다.

### 나가 있어도 무엇을 하는 중인지 보입니다

다른 플랜으로 가시든, 다른 메뉴로 가시든, 홈으로 나가시든 **화면 왼쪽 아래에
표시가 따라다닙니다.**

> ⟳ 이웃 나눔 · 프로덕트 요구사항 만드는 중 (1/5)

**누르면 그 일이 벌어지고 있는 화면으로 바로 갑니다.** 어느 플랜의 무슨 일인지 함께
적혀 있어서, 플랜이 여러 개여도 헷갈리지 않습니다.

산출물 생성뿐 아니라 **스티치에 화면 만들기**, **AI 에이전트 답변**도 같은 자리에
나옵니다. 돌고 있는 일이 없으면 아무것도 안 보입니다.

### 도중에 멈추기

잘못 걸었거나 오래 걸린다 싶으면 **`■ 멈추기`** 를 누르세요.
진행 표시 오른쪽에 있습니다.

> ⟳ 3/5 · 정보구조도를 만들고 있습니다.                    `■ 멈추기`

**만들어진 단계는 그대로 남습니다.** 크레딧도 받은 단계까지만 빠집니다.
멈춘 자리부터는 아래 `이어서 만들기` 로 이어 갈 수 있으니, 처음부터 다시 만들 필요가 없습니다.

> 각 산출물 화면에서 `생성 중입니다` 를 보고 있을 때도 그 자리에 `멈추기` 가 있습니다.

### 창을 닫으면

**닫은 시점까지 만든 것은 저장되고, 거기서 멈춥니다.**

다시 들어오면 화면 위에 이런 안내가 뜹니다.

> 전체 자동 생성이 **3/5 단계**에서 멈췄습니다.
> `이어서 만들기`  `그만두기`

- **`이어서 만들기`** — 남은 단계부터 이어 갑니다. 앞부분을 다시 만들지 않습니다.
- **`그만두기`** — 안내만 없앱니다. 만들어진 것은 그대로 남습니다.

못 만든 단계의 크레딧은 빠져나가지 않았으니 손해가 없습니다.

## 단계별로 만들기

한 문서만 다시 만들고 싶을 때는 그 문서 화면에서 **`AI로 생성`** 을 누릅니다.
이미 만들어져 있으면 버튼이 **`다시 생성`** 으로 바뀌고, 누르면 확인을 한 번 거칩니다.

> **`다시 생성`은 기존 내용을 덮어씁니다.** 직접 고쳐 둔 부분이 있다면 사라집니다.
> 아까우면 먼저 개요 화면에서 `현재 상태 저장` 을 눌러 두세요.

### 한 번에 다 안 나올 때

**유저 플로우**와 **와이어프레임**은 한 번에 전부 만들지 않습니다. 한 요청에 너무 많이
담으면 하나하나가 얕아지기 때문입니다. 대신 **덧붙이는 버튼**이 따로 있습니다.

| 단계 | 버튼 | 하는 일 |
| --- | --- | --- |
| 유저 플로우 | `플로우 더 만들기` | 있는 플로우는 두고 새 플로우만 뒤에 붙입니다 |
| 와이어프레임 | `AI로 생성` → 화면 고르기 | 고른 화면만 만듭니다 |

둘 다 **`다시 생성` 과 다릅니다.** `다시 생성` 은 그 문서를 통째로 갈아엎습니다.

### 완료 표시는 무엇을 보고 정하나요

**지금 그 문서에 내용이 들어 있는지**만 봅니다. AI로 만들었는지 직접 썼는지는 상관없습니다.
그래서 항목을 전부 지우면 다시 `미생성` 으로 돌아가고, 손으로 써 넣으면 `생성 완료` 가 됩니다.
개요의 단계 카드, 사이드바의 점, 홈 화면의 `산출물 3/5`, 내보내기 선택지가 모두 같은 기준입니다.

### 버튼이 눌리지 않을 때

앞 문서가 없으면 버튼이 흐리게 잠기고 이유가 표시됩니다.

| 만들려는 것 | 먼저 있어야 하는 것 |
| --- | --- |
| 기능명세서 | 프로덕트 요구사항 |
| 정보구조도 | 기능명세서 |
| 유저 플로우 | 정보구조도 |
| 와이어프레임 | 정보구조도 |

## AI가 만든 것 확인하기 — 승인과 거절

**AI가 만든 것은 초안입니다.** 그대로 쓰지 마시고 한 번씩 읽어 보세요.

기능명세서에서 AI가 새로 만든 항목에는 **`신규`** 배지가 붙습니다.
확인한 것과 아직 안 본 것을 구분하기 위한 표시입니다.

배지가 붙은 항목이 하나라도 있으면 화면 아래에 **검토 바**가 떠 있습니다.

| 버튼 | 하는 일 |
| --- | --- |
| **`일괄 승인`** | 전부 확인 처리합니다. 내용은 그대로 남습니다 |
| `일괄 거절` | 전부 **삭제**합니다 |
| `‹` `3 / 12` `›` | 하나씩 넘겨 봅니다. 넘길 때마다 그 항목이 화면에서 선택됩니다 |
| **`승인`** | 지금 항목의 배지만 지웁니다 |
| `거절` | 지금 항목을 **삭제**합니다 |

승인하거나 거절하면 그 항목이 목록에서 빠지고 다음 항목이 올라옵니다.
계속 누르면 끝까지 처리되고, 다 끝나면 검토 바가 사라집니다.

> **`거절`은 삭제입니다.** 하위 항목도 함께 지워집니다. 되돌리려면 미리 저장해 둔
> 버전으로 복원해야 합니다.
>
> **읽어 보고 괜찮으면 `일괄 승인` 하나로 끝내면 됩니다.** 배지를 지우는 것뿐이라
> 내용은 아무것도 바뀌지 않습니다.

**직접 추가한 항목에는 배지가 붙지 않습니다.** 내가 만든 것을 다시 확인할 이유가 없기 때문입니다.

## 크레딧

문서를 만들 때마다 조금씩 차감되고, **한국 시각 자정에 다시 채워집니다.**

크레딧은 **계정에 붙습니다.** 어느 컴퓨터에서 들어오셔도 같은 잔량을 보십니다.

| 만드는 것 | 크레딧 |
| --- | --- |
| 프로덕트 요구사항 | 3 |
| 기능명세서 | 5 |
| 정보구조도 | 4 |
| 유저 플로우 | 3 |
| 와이어프레임 | 5 |
| AI 에이전트 메시지 1건 | 1 |
| 기능 배치 | 2 |

**전체 자동 생성 한 번 = 20 크레딧**입니다.

지금 하루 한도는 **200** 입니다. 전체 자동 생성을 하루에 열 번 할 수 있는 양입니다.
화면의 `(임시)` 표시는 정식 요금제를 붙이기 전이라는 뜻입니다.

### 받은 것에만 값이 듭니다

- 중간에 멈추면 **만들어진 단계까지만** 빠집니다
- **AI 가 만들지 못해 기본 생성기로 대신했을 때는 크레딧이 들지 않습니다**
- 잔량이 모자라면 아예 시작하지 않습니다

무엇에 언제 썼는지는 **설정 → 사용량**에서 보실 수 있습니다.

## 결과가 마음에 안 들 때

| 상황 | 이렇게 해 보세요 |
| --- | --- |
| 내용이 두루뭉술함 | 개요 화면에서 서비스 아이디어를 더 자세히 고치고 다시 생성 |
| 중요한 기능이 빠짐 | 그 문서에서 직접 추가하거나, AI 에이전트에게 "○○ 기능도 넣어줘" 라고 요청 |
| 우리 서비스와 안 맞음 | 3단계 위저드의 `참고 서비스` 와 `반드시 포함할 기능` 을 채우고 다시 생성 |
| 일부만 고치고 싶음 | 다시 생성하지 말고 그 항목만 직접 수정 (덮어쓰기를 피할 수 있습니다) |

> 전체를 다시 만드는 것보다 **직접 고치는 편이 빠른 경우가 많습니다.**
> 크레딧도 들지 않고, 다른 부분이 바뀔 위험도 없습니다.
