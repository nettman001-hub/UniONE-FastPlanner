# 4. 내보내기와 공유

`/plans/{id}/export` 화면에서 완성된 기획서를 밖으로 가져갑니다.

## 산출물 선택

상단에서 어떤 산출물을 포함할지 고릅니다. 기본은 생성된 것 전체이며,
아직 만들지 않은 산출물은 선택할 수 없습니다.

이 선택은 **마크다운**과 **문서 보기**에 반영됩니다. CSV·JSON·번들은 항상 전체를 담습니다.

## 파일 형식 6종

| 형식 | 확장자 | 쓰임 |
| --- | --- | --- |
| 마크다운 | `.md` | Notion·GitHub·Confluence 에 그대로 붙여넣기 |
| 기능명세서 CSV | `.csv` | 엑셀·구글 시트. 요구사항–기능을 행으로 펼침 |
| 정보구조도 CSV | `.csv` | Depth 별 페이지 목록 |
| 플랜 JSON | `.json` | 백업, 다른 기기로 이동, 팀원에게 전달 |
| 에이전트 번들 | `.json` | Cursor·Claude Code 같은 코딩 에이전트용 |
| Mermaid 플로우 | `.md` | 모든 유저 플로우를 Mermaid 코드로 묶음 |

CSV 는 한글이 깨지지 않도록 BOM 을 붙여 저장합니다. 엑셀에서 바로 열립니다.

파일명은 서비스명을 딴 슬러그가 붙습니다. 예) `산책메이트-기능명세서.csv`

## 미리보기

형식 탭을 눌러 결과를 미리 확인하고 복사할 수 있습니다.

## 이미지 (디자인 전달용)

와이어프레임을 SVG 또는 PNG 로 뽑습니다.

| 버튼 | 결과 |
| --- | --- |
| SVG | 벡터. Figma 에 그대로 붙여 넣고 크기를 키워도 깨지지 않습니다 |
| PNG | 2배 해상도 비트맵. 슬라이드·문서 삽입용 |
| 전체 PNG 내려받기 | 모든 와이어프레임을 순서대로 저장 |

유저 플로우 이미지는 **유저 플로우 화면**에서 캔버스를 그대로 SVG·PNG 로 내려받습니다.
현재 테마의 색이 실제 색값으로 변환되어 저장되므로 다른 도구에서도 그대로 보입니다.

## 보기 전용 링크

문서를 링크에 담아 전달합니다.

1. **[링크 만들기]** 를 누릅니다.
2. 생성된 링크를 복사해 전달합니다.
3. 받는 사람은 읽기만 할 수 있습니다.

동작 방식:

- 문서 내용이 링크의 `#` 뒷부분에 압축되어 담깁니다.
- **`#` 뒷부분은 브라우저 규칙상 서버로 전송되지 않습니다.** 서버에 아무것도 저장되지 않습니다.
- 대화 기록과 버전 스냅샷은 빼고 문서만 담아 링크를 짧게 유지합니다.
- 링크가 너무 길면 경고가 뜹니다. 이 경우 플랜 JSON 파일로 전달하는 편이 안전합니다.

## 코딩 에이전트 연동

**에이전트 번들**은 ID 참조를 모두 이름까지 펼쳐 담은 JSON 입니다.
에이전트가 다른 문서를 열지 않아도 화면과 기능의 관계를 해석할 수 있습니다.

### 번들 구조

| 키 | 내용 |
| --- | --- |
| `product` | 서비스명·한 줄 소개·타겟·플랫폼 |
| `prd` | 목표·페르소나·역할·범위·제약 |
| `requirements` | 요구사항 → 기능 → 상세명세 트리 |
| `informationArchitecture` | 페이지 계층·경로·연결 기능 이름 |
| `userFlows` | 플로우 노드·엣지 + Mermaid 원문 |
| `wireframes` | 화면별 블록 구성과 기획 메모 |
| `coverage` | 산출물 5종의 생성 여부 |

### 사용법

1. 번들을 내려받아 프로젝트 저장소에 넣습니다. 예) `plan-bundle.json`
2. 코딩 에이전트에게 지시합니다.

```
plan-bundle.json 을 읽고 informationArchitecture 의 각 페이지를 라우트로,
requirements[].features[].specifications 를 구현 단위로 삼아 작업 계획을 세워줘.
```

상세명세의 **기본 흐름**과 **인수 조건**이 그대로 구현 기준과 테스트 기준이 됩니다.

## 문서 보기와 인쇄

**[문서 보기]** 를 켜면 선택한 산출물을 읽기 좋은 형태로 렌더링합니다.
이 상태에서 **[인쇄]** 를 누르면 그 영역만 출력되므로 PDF 저장에 적합합니다.

## 백업과 이동

문서는 브라우저에만 저장되므로, 기기를 바꾸거나 브라우저 데이터를 지우기 전에는
반드시 **플랜 JSON** 을 내려받아 두세요.

복원은 홈 화면에서 **[플랜 가져오기]** 를 누르거나 JSON 파일을 화면에 끌어다 놓으면 됩니다.
