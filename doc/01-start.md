# 1. 시작하기

## 로그인

UniBoard 는 로그인해야 쓸 수 있습니다. 만든 기획서를 계정에 저장해 두었다가
다른 컴퓨터에서도 이어서 볼 수 있게 하기 위해서입니다.

### 계정이 있는 경우

이메일과 비밀번호를 넣고 **`로그인`** 을 누릅니다.

### 계정이 없는 경우

**`회원가입`** 탭을 누릅니다. 화면에 나오는 안내에 따라 셋 중 하나입니다.

| 화면에 이렇게 나오면 | 이렇게 하세요 |
| --- | --- |
| 이메일·비밀번호·이름만 있음 | 그대로 채우고 가입하면 됩니다 |
| **초대 코드** 칸이 있음 | 관리자에게 코드를 받아 넣으세요 |
| "지금은 새 계정을 만들 수 없습니다" | 관리자에게 계정을 요청하세요 |

비밀번호는 **8자 이상**이면 됩니다.

> **비밀번호 찾기 기능은 아직 없습니다.** 잊어버리셨다면 관리자에게 문의하세요.

---

## 화면 둘러보기

### 홈 — 내 기획서 목록

로그인하면 처음 보이는 화면입니다.

| 위치 | 무엇 |
| --- | --- |
| 맨 위 왼쪽 | 서비스 상태 표시 — 저장 상태, AI 사용 여부, 남은 크레딧 |
| 맨 위 오른쪽 | 계정 버튼. 누르면 내 이메일과 **로그아웃** |
| 그 아래 | **`＋ 기획하기`** · `플랜 가져오기` · `설명서` |
| 가운데 | 내가 만든 기획서 카드들 |

### 기획서 안 — 작업 화면

기획서 카드를 누르면 들어갑니다.

```
┌──────────────────────────────────────────────┐
│  ‹ 로고  서비스명       저장됨  크레딧  AI 에이전트  계정 │  ← 상단 바
├──────────┬───────────────────────────────────┤
│ 개요      │                                   │
│ 프로덕트… │                                   │
│ 기능명세서 │         지금 보고 있는 문서          │
│ 정보구조도 │                                   │
│ 유저 플로우│                                   │
│ 와이어…   │                                   │
│ 내보내기  │                                   │
│ ─────    │                                   │
│ 설명서    │                                   │
└──────────┴───────────────────────────────────┘
```

**왼쪽 메뉴**는 만드는 순서대로 놓여 있습니다. 위에서부터 차례로 내려가면 됩니다.

메뉴 오른쪽의 작은 점이 진행 상태입니다.

- 🟢 초록 점 — 만들어졌습니다
- ⚪ 회색 점 — 아직 안 만들었습니다
- 🔄 도는 표시 — 지금 만드는 중입니다

**휴대폰**에서는 왼쪽 메뉴가 화면 아래쪽 탭으로 바뀝니다.

---

## 상단 바 읽는 법

| 표시 | 뜻 |
| --- | --- |
| `‹ 로고` | 누르면 기획서 목록으로 나갑니다 |
| `저장 중` | 계정에 올리는 중입니다 |
| `저장됨` | 계정에 저장이 끝났습니다 |
| `저장 안 됨` | 계정에 못 올렸습니다. **작업 내용은 이 컴퓨터에 남아 있으니 사라지지 않습니다** |
| `200 / 200` | 남은 크레딧 / 하루 한도 |
| `AI 에이전트` | 오른쪽에 대화창을 엽니다 |

---

## 저장은 어떻게 되나요

**저장 버튼이 없습니다.** 고치면 바로 저장됩니다.

정확히는 이렇게 동작합니다.

1. 입력칸에서 커서를 빼는 순간 → **이 컴퓨터에 즉시 저장**
2. 약 1초 뒤 → **내 계정에 저장** (상단이 `저장됨` 으로 바뀝니다)

두 단계로 나뉘어 있어서 좋은 점이 있습니다.

- **인터넷이 끊겨도 작업이 멈추지 않습니다.** 계속 고칠 수 있고, 연결되면 알아서 올라갑니다.
- 브라우저를 갑자기 닫아도 이 컴퓨터에는 남아 있어서, 다음에 들어오면 다시 올라갑니다.
