# 8. 자주 묻는 질문

## 계정

### 비밀번호를 잊어버렸어요

**비밀번호 찾기 기능이 아직 없습니다.** 관리자에게 문의해 주세요.

### 회원가입이 안 됩니다

화면에 나오는 안내에 따라 다릅니다.

| 화면 | 뜻 | 해결 |
| --- | --- | --- |
| 초대 코드 칸이 있음 | 코드를 아는 사람만 가입 가능합니다 | 관리자에게 코드를 받으세요 |
| "지금은 새 계정을 만들 수 없습니다" | 가입이 닫혀 있습니다 | 관리자에게 계정을 요청하세요 |
| "이미 가입된 이메일입니다" | 그 이메일로 이미 계정이 있습니다 | 로그인 탭에서 로그인하세요 |

### 로그아웃했더니 기획서가 다 사라졌어요

**정상입니다.** 기획서는 계정에 있고, 이 컴퓨터에 있던 사본만 지운 것입니다.
**같은 계정으로 다시 로그인하면 그대로 돌아옵니다.**

한 컴퓨터를 여러 사람이 쓸 때 앞사람 기획서가 뒷사람에게 보이지 않게 하려는 것입니다.

### 여러 명이 같은 계정을 써도 되나요

됩니다. 다만 **기획서를 함께 보고 함께 고치게 됩니다.**
각자 자기 것만 갖고 싶다면 각자 계정을 만드세요.

---

## 기획서가 안 보여요

### 만든 기획서가 목록에 없습니다

순서대로 확인해 보세요.

1. **어느 계정으로 로그인했는지** — 오른쪽 위 계정 버튼에 이메일이 나옵니다.
   다른 계정으로 들어오면 그 계정 것만 보입니다.
2. **로그인 기능이 생기기 전에 만든 것인지** — 처음 로그인할 때
   `로그인 전에 이 브라우저에서 만든 플랜이 N개 있습니다` 안내가 뜹니다.
   **`내 계정으로 가져오기`** 를 눌러야 올라옵니다.
3. 그래도 없으면 관리자에게 문의해 주세요.

### 다른 컴퓨터에서 안 보입니다

같은 계정으로 로그인했는지 확인하세요. 로그인했는데도 안 보인다면,
원래 컴퓨터에서 상단이 **`저장됨`** 인지 확인해 주세요. `저장 안 됨` 이면
아직 계정에 안 올라간 것입니다.

---

## 저장

### `저장 안 됨` 이 계속 떠 있어요

계정에 못 올리고 있다는 뜻입니다.
**작업하신 내용은 이 컴퓨터에 남아 있으니 지금 당장 사라지지는 않습니다.**

1. 인터넷 연결을 확인하세요.
2. 새로고침해 보세요. 로그인이 풀렸다면 로그인 화면으로 갑니다.
3. 그래도 그대로면 **관리자에게 알려 주세요.**

이 상태에서도 계속 작업하셔도 됩니다. 연결이 돌아오면 알아서 올라갑니다.

### 저장 버튼이 어디 있나요

**없습니다.** 고치면 바로 저장됩니다. 입력칸에서 커서를 빼는 순간 반영됩니다.

### 실수로 지웠어요

| 지운 것 | 되살릴 수 있나 |
| --- | --- |
| 요구사항·기능·화면 등 | 개요 화면에서 **미리 저장해 둔 버전**이 있으면 복원 가능 |
| 기획서 전체 | 내보내 둔 **플랜 JSON** 파일이 있으면 가져오기로 복원 |
| 둘 다 없음 | 되살릴 수 없습니다 |

> 크게 손보기 전에는 개요 화면에서 **`현재 상태 저장`** 을 눌러 두세요.

## AI 생성

### 생성이 멈춘 것 같아요

버튼이 **진한 색에 `생성중`** 이면 정상적으로 일하는 중입니다.
문서에 따라 30초에서 몇 분까지 걸립니다.

**다른 메뉴로 옮겨 다녀도 계속됩니다.** 왼쪽 메뉴에서 돌아가는 표시로 진행 상황을 볼 수 있습니다.

### 창을 닫았다 돌아오니 "3/5 단계에서 멈췄습니다" 가 떠요

정상입니다. 보고 있는 사람이 없으면 다음 단계로 넘어가지 않고 멈춥니다.
쓰지도 않을 것을 계속 만들지 않기 위해서입니다.

- 만들어진 단계는 이미 반영돼 있습니다.
- **`이어서 만들기`** 를 누르면 남은 단계부터 이어 갑니다.
- 못 만든 단계의 크레딧은 나가지 않았습니다.

### 크레딧이 부족합니다

**매일 자동으로 다시 채워집니다.** 하루 한도는 200 이고, 전체 자동 생성 한 번에 20 이 듭니다.

급하다면 **전체 자동 생성 대신 필요한 문서만** 따로 만드세요.

| 만드는 것 | 크레딧 |
| --- | --- |
| 프로덕트 요구사항 | 3 |
| 기능명세서 | 5 |
| 정보구조도 | 4 |
| 유저 플로우 | 3 |
| 와이어프레임 | 5 |
| AI 에이전트 메시지 1건 | 1 |

### 결과가 우리 서비스와 안 맞아요

**아이디어를 더 자세히 적고 다시 만들어 보세요.** 개요 화면에서 서비스 아이디어를
고칠 수 있습니다. 누가, 어떤 불편을 겪고, 이 서비스가 그걸 어떻게 없애 주는지를
세 문장 정도로 적으면 결과가 크게 달라집니다.

`반드시 포함할 기능` 에 꼭 들어가야 하는 것을 적어 두면 빠뜨리지 않습니다.

> 다만 **전체를 다시 만드는 것보다 직접 고치는 편이 빠른 경우가 많습니다.**
> 크레딧도 안 들고, 다른 부분이 바뀔 위험도 없습니다.

### `내장 생성기` 라고 나옵니다

AI 대신 정해진 규칙으로 문서를 만드는 모드입니다. 구조는 똑같이 나오지만 내용은
일반적입니다. 관리자에게 문의해 주세요. **이 상태에서도 편집·검증·내보내기는 모두 그대로 됩니다.**

### `다시 생성` 을 눌렀더니 고쳐 둔 게 사라졌어요

**`다시 생성`은 그 문서를 통째로 새로 만듭니다.** 직접 고친 부분도 함께 사라집니다.

미리 저장해 둔 버전이 있으면 개요 화면에서 복원하세요.
앞으로는 **일부만 고치고 싶을 때는 다시 생성하지 마시고** 해당 항목을 직접 수정하거나
AI 에이전트에게 그 부분만 요청하세요.

## 문서 작성

### `신규` 배지는 뭔가요

**AI가 만들었고 아직 확인 안 한 항목**이라는 표시입니다.
읽어 보고 괜찮으면 아래쪽 검토 바에서 **`일괄 승인`** 을 누르면 배지가 사라집니다.
**내용은 아무것도 바뀌지 않습니다.**

`거절` 은 **삭제**이니 주의하세요.

### 정합성 검사 오류가 계속 떠요

각 지적을 누르면 해당 자리로 이동합니다. 자주 나오는 것들:

| 지적 | 해결 |
| --- | --- |
| 화면에 배치되지 않은 기능 | 정보구조도 → 그 화면 → `상세 기능 연결` 에서 체크 |
| 상세 명세가 없는 필수 기능 | 기능명세서에서 그 기능에 상세 기능 추가 |
| 도달할 수 없는 단계 | 유저 플로우에서 그 단계로 들어오는 연결선 추가 |
| 분기가 하나뿐인 조건 | 실패·거절 경로를 추가 |

### 표가 화면 밖으로 넘쳐요

넓은 표는 좌우로 스크롤됩니다. 표 위에 커서를 두고 좌우로 밀어 보세요.

---

## 내보내기

### 엑셀에서 한글이 깨져요

깨지지 않도록 처리되어 있습니다. 파일을 두 번 눌러서 열어 보세요.
그래도 깨지면 엑셀에서 `데이터 → 텍스트/CSV 가져오기` 로 열고 인코딩을 `UTF-8` 로 지정하세요.

### 공유 링크가 너무 길어요

기획서 내용이 링크 안에 통째로 담기기 때문입니다. 내용이 많으면 링크도 길어집니다.

경고가 뜰 정도로 길면 **플랜 JSON 파일**로 전달하세요.
받는 사람이 홈에서 `플랜 가져오기` 로 열면 됩니다.

### PDF로 저장하고 싶어요

내보내기 화면에서 **`문서 보기`** 를 켜고 **`인쇄`** 를 누른 뒤,
인쇄 창에서 프린터 대신 **`PDF로 저장`** 을 고르세요.

## 그 외

### 휴대폰에서도 쓸 수 있나요

됩니다. 왼쪽 메뉴가 화면 아래 탭으로 바뀝니다.
다만 마인드맵이나 와이어프레임 편집처럼 넓은 화면이 필요한 작업은
**컴퓨터에서 하시는 편이 훨씬 편합니다.**

### 내가 쓴 내용이 어디로 가나요

- 기획서는 **내 계정에만** 저장되고, 다른 사용자는 볼 수 없습니다.
- **AI로 생성할 때만** 기획서 내용이 AI 서비스로 전달됩니다.
- 공유 링크는 **서버를 거치지 않습니다.** 내용이 링크 안에 담겨 전달됩니다.

### 여기에 없는 문제입니다

관리자에게 문의해 주세요. 이때 아래를 함께 알려 주시면 훨씬 빨리 해결됩니다.

- 어느 화면에서 무엇을 눌렀을 때인지
- 화면에 나온 메시지 (있다면 그대로)
- 상단이 `저장됨` 이었는지 `저장 안 됨` 이었는지
