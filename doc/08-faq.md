# 8. 자주 묻는 질문

## 계정

### 비밀번호를 잊어버렸어요

**비밀번호 찾기 기능이 아직 없습니다.** 관리자에게 문의해 주세요.

### 회원가입이 안 됩니다

화면에 나오는 안내에 따라 다릅니다.

| 화면 | 뜻 | 해결 |
| --- | --- | --- |
| 초대 코드 칸이 있음 | 코드를 아는 사람만 가입 가능합니다 | 관리자에게 코드를 받으세요 |
| "지금은 새 계정을 만들 수 없습니다" | 가입이 닫혀 있습니다 | 관리자에게 계정을 요청하세요 |
| "이미 가입된 이메일입니다" | 그 이메일로 이미 계정이 있습니다 | 로그인 탭에서 로그인하세요 |

### 로그아웃했더니 기획서가 다 사라졌어요

**정상입니다.** 기획서는 계정에 있고, 이 컴퓨터에 있던 사본만 지운 것입니다.
**같은 계정으로 다시 로그인하면 그대로 돌아옵니다.**

한 컴퓨터를 여러 사람이 쓸 때 앞사람 기획서가 뒷사람에게 보이지 않게 하려는 것입니다.

### 여러 명이 같은 계정을 써도 되나요

됩니다. 다만 **기획서를 함께 보고 함께 고치게 됩니다.**
각자 자기 것만 갖고 싶다면 각자 계정을 만드세요.

---

## 기획서가 안 보여요

### 만든 기획서가 목록에 없습니다

순서대로 확인해 보세요.

1. **어느 계정으로 로그인했는지** — 오른쪽 위 계정 버튼에 이메일이 나옵니다.
   다른 계정으로 들어오면 그 계정 것만 보입니다.
2. **로그인 기능이 생기기 전에 만든 것인지** — 처음 로그인할 때
   `로그인 전에 이 브라우저에서 만든 플랜이 N개 있습니다` 안내가 뜹니다.
   **`내 계정으로 가져오기`** 를 눌러야 올라옵니다.
3. 그래도 없으면 관리자에게 문의해 주세요.

### 다른 컴퓨터에서 안 보입니다

같은 계정으로 로그인했는지 확인하세요. 로그인했는데도 안 보인다면,
원래 컴퓨터에서 상단이 **`저장됨`** 인지 확인해 주세요. `저장 안 됨` 이면
아직 계정에 안 올라간 것입니다.

---

## 저장

### `저장 안 됨` 이 계속 떠 있어요

계정에 못 올리고 있다는 뜻입니다.
**작업하신 내용은 이 컴퓨터에 남아 있으니 지금 당장 사라지지는 않습니다.**

1. 인터넷 연결을 확인하세요.
2. 새로고침해 보세요. 로그인이 풀렸다면 로그인 화면으로 갑니다.
3. 그래도 그대로면 **관리자에게 알려 주세요.**

이 상태에서도 계속 작업하셔도 됩니다. 연결이 돌아오면 알아서 올라갑니다.

### 저장 버튼이 어디 있나요

**없습니다.** 고치면 바로 저장됩니다. 입력칸에서 커서를 빼는 순간 반영됩니다.

### 실수로 지웠어요

| 지운 것 | 되살릴 수 있나 |
| --- | --- |
| 요구사항·기능·화면 등 | 개요 화면에서 **미리 저장해 둔 버전**이 있으면 복원 가능 |
| 기획서 전체 | 내보내 둔 **플랜 JSON** 파일이 있으면 가져오기로 복원 |
| 둘 다 없음 | 되살릴 수 없습니다 |

> 크게 손보기 전에는 개요 화면에서 **`현재 상태 저장`** 을 눌러 두세요.

## AI 생성

### 생성이 멈춘 것 같아요

버튼이 **진한 색에 `생성중`** 이면 정상적으로 일하는 중입니다.
문서에 따라 30초에서 몇 분까지 걸립니다.

**다른 메뉴로 옮겨 다녀도 계속됩니다.** 왼쪽 메뉴에서 돌아가는 표시로 진행 상황을 볼 수 있습니다.

### 창을 닫았다 돌아오니 "3/5 단계에서 멈췄습니다" 가 떠요

정상입니다. 보고 있는 사람이 없으면 다음 단계로 넘어가지 않고 멈춥니다.
쓰지도 않을 것을 계속 만들지 않기 위해서입니다.

- 만들어진 단계는 이미 반영돼 있습니다.
- **`이어서 만들기`** 를 누르면 남은 단계부터 이어 갑니다.
- 못 만든 단계의 크레딧은 나가지 않았습니다.

### 크레딧이 부족합니다

**매일 자동으로 다시 채워집니다.** 하루 한도는 200 이고, 전체 자동 생성 한 번에 20 이 듭니다.

급하다면 **전체 자동 생성 대신 필요한 문서만** 따로 만드세요.

| 만드는 것 | 크레딧 |
| --- | --- |
| 프로덕트 요구사항 | 3 |
| 기능명세서 | 5 |
| 정보구조도 | 4 |
| 유저 플로우 | 3 |
| 와이어프레임 | 5 |
| AI 에이전트 메시지 1건 | 1 (고급 2) |

### 결과가 우리 서비스와 안 맞아요

**아이디어를 더 자세히 적고 다시 만들어 보세요.** 개요 화면에서 서비스 아이디어를
고칠 수 있습니다. 누가, 어떤 불편을 겪고, 이 서비스가 그걸 어떻게 없애 주는지를
세 문장 정도로 적으면 결과가 크게 달라집니다.

`반드시 포함할 기능` 에 꼭 들어가야 하는 것을 적어 두면 빠뜨리지 않습니다.

> 다만 **전체를 다시 만드는 것보다 직접 고치는 편이 빠른 경우가 많습니다.**
> 크레딧도 안 들고, 다른 부분이 바뀔 위험도 없습니다.

### `기본 생성기` 라고 나옵니다

AI 대신 정해진 규칙으로 문서를 만드는 모드입니다. 구조는 똑같이 나오지만 내용은
일반적입니다. 관리자에게 문의해 주세요. **이 상태에서도 편집·검증·내보내기는 모두 그대로 됩니다.**

### 전체 자동 생성을 잘못 걸었어요. 멈출 수 있나요

**네.** 진행 표시 오른쪽의 **`■ 멈추기`** 를 누르세요. 각 산출물 화면의
`생성 중입니다` 안내에도 같은 버튼이 있습니다.

- **만들어진 단계는 그대로 남습니다.** 지워지지 않습니다.
- **크레딧은 받은 단계까지만** 빠집니다.
- 멈춘 자리부터 **`이어서 만들기`** 로 이어 갈 수 있습니다.

> 예: 2/5 에서 멈추면 프로덕트 요구사항·기능명세서는 남고, 정보구조도부터 이어서 만듭니다.

### AI 에이전트에 잘못 시켰어요. 멈출 수 있나요

**네.** `생각하는 중…` 옆의 **`■ 멈추기`** 를 누르세요.

**크레딧은 차감되지 않고 문서도 그대로**입니다. 질문은 대화에 남아 있으니
`다시 보내기` 로 그대로 다시 시키거나, 입력창에 고쳐 적어 새로 보내면 됩니다.

> 이미 나간 요청 자체를 되돌리지는 못합니다. 다만 **그 결과가 문서에 반영되지는 않습니다.**

### AI가 이런 답을 했어요

| 화면에 나온 문장 | 뜻 | 할 일 |
| --- | --- | --- |
| 결과를 정리하지 못했습니다 | 결과 형식이 어긋났습니다 | **다시 시도**하면 대부분 됩니다 |
| 한 번에 만들기에는 요청이 큽니다 | 한 번에 만들기엔 요청이 많습니다 | **나눠서** 요청하세요 (예: 기능 두세 개씩) |
| 지금 요청이 몰려 있습니다 | 일시적으로 붐빕니다 | 잠시 후 다시 시도하세요 |
| AI 생성 설정에 문제가 있습니다 | 서비스 쪽 설정 문제입니다 | 다시 눌러도 안 됩니다. **관리자에게 알려 주세요** |

> **한 번에 너무 많이 시키지 마세요.** 기능 다섯 개에 상세 명세까지 한꺼번에
> 요청하면 결과가 길어져 중간에 잘립니다. 두세 개씩 나눠 시키면 훨씬 안정적이고
> 결과도 좋습니다.

### `다시 생성` 을 눌렀더니 고쳐 둔 게 사라졌어요

**`다시 생성`은 그 문서를 통째로 새로 만듭니다.** 직접 고친 부분도 함께 사라집니다.

미리 저장해 둔 버전이 있으면 개요 화면에서 복원하세요.
앞으로는 **일부만 고치고 싶을 때는 다시 생성하지 마시고** 해당 항목을 직접 수정하거나
AI 에이전트에게 그 부분만 요청하세요.

### 개요에는 `생성 완료` 인데 열어 보면 비어 있어요

**이제 그런 일은 생기지 않습니다.** 완료 표시는 **지금 그 문서에 내용이 들어 있는지**만 보고
정합니다. 만든 적이 있는지는 따지지 않습니다.

그래서 이렇게 동작합니다.

- 문서의 항목을 **전부 지우면** 다시 `미생성` 으로 돌아가고, 버튼도 `AI로 생성` 이 됩니다.
- **직접 손으로 써 넣어도** `생성 완료` 가 됩니다. AI로 만들었는지는 상관없습니다.
- 홈 화면의 `산출물 3/5` 와 사이드바의 점, 내보내기 화면의 선택지도 **모두 같은 기준**입니다.

> 예전에는 "한 번 생성했다" 는 기록만 보고 표시했습니다. 그래서 내용이 사라져도 완료로 남아,
> 개요는 `생성 완료` 인데 다음 단계는 `기능명세서를 먼저 만들어 주세요` 라고 서로 다른 말을
> 하는 일이 있었습니다.

## 문서 작성

### 유저 플로우가 3개밖에 안 만들어졌어요. 다 만들어야 하나요?

**아니요. 3개면 대개 충분합니다.** 화면이 24개여도 그렇습니다.

플로우는 **화면 목록이 아니라 갈라지는 지점**을 그리는 문서입니다. 화면 수와 플로우 수는
애초에 맞출 대상이 아닙니다.

| 그릴 값어치가 있는 것 | 안 그려도 되는 것 |
| --- | --- |
| 되돌릴 수 없는 행동 — 결제 · 삭제 · 전송 | 들어가서 보기만 하는 화면 — 목록 · 상세 · 조회 |
| 권한이 갈리는 지점 — 로그인 · 승인 · 본인인증 | 단계가 하나뿐인 화면 |
| 여러 단계를 거치는 입력 · 외부 시스템(배송 · 알림 · 정산) | |

**뒤 단계에는 지장이 없습니다.** 와이어프레임은 **정보구조도**를 보고 만듭니다.
플로우가 2~3개뿐이어도 와이어프레임 품질은 달라지지 않습니다.

`아직 플로우에 없는 화면 N개` 는 **알림일 뿐, 0으로 만들어야 하는 숫자가 아닙니다.**
정합성 검사에서도 `제안` 등급이라 넘어가셔도 됩니다.

### 그래도 플로우를 더 만들고 싶어요

유저 플로우 화면 위쪽 **`플로우 더 만들기`** 를 누르세요. **지금 있는 플로우는 그대로 두고**
새 플로우만 뒤에 붙습니다. 아직 어느 플로우에도 안 나오는 화면부터 다룹니다.

> **`다시 생성` 과 다릅니다.** `다시 생성` 은 전부 갈아엎어 손으로 다듬은 것도 사라집니다.
> `플로우 더 만들기` 는 아무것도 지우지 않습니다.

### 플로우 아래의 `SVG` · `PNG` 는 꼭 받아야 하나요

**아니요. 필요할 때만 쓰는 선택지입니다.**

지금 보고 있는 **플로우 하나**를 그림 파일로 내려받는 버튼입니다. 디자이너에게 여정을
따로 보여 줄 일이 있을 때 쓰시면 되고, 모든 플로우의 그림을 만들어 전달해야 하는 것은
아닙니다. 플로우는 `내보내기` 에서 문서·JSON 에 이미 함께 담깁니다.

### `재생성 필요` 라고 빨갛게 떠요

**이 문서가 앞 단계보다 뒤처져 있다**는 뜻입니다. 고장이 아닙니다.

기능명세서에 기능을 추가하면 그 뒤 단계(정보구조도 · 유저 플로우 · 와이어프레임)는
새 기능을 모르는 채로 남습니다. 그 상태를 알려 주는 표시입니다.

| 어디에 뜨나 | 무엇을 하면 되나 |
| --- | --- |
| 정보구조도 — `화면에 배치되지 않은 기능 N개` | `배치하기` 를 눌러 새 기능의 자리를 정합니다 |
| 와이어프레임 — `N개 화면의 와이어프레임이 최신이 아닙니다` | `이 화면들 다시 만들기` 를 누릅니다 |

**항목 하나를 손으로 고쳐서 되는 문제가 아닐 때만** 이 표시가 붙습니다.
`사용자 역할이 정의되지 않았습니다` 처럼 직접 채우면 되는 지적에는 붙지 않습니다.

> **유저 플로우에는 붙지 않습니다.** 안 덮인 화면은 결함이 아니기 때문입니다.
> 바로 위 항목을 보세요.

### `신규` 배지는 뭔가요

**AI가 만들었고 아직 확인 안 한 항목**이라는 표시입니다.
읽어 보고 괜찮으면 아래쪽 검토 바에서 **`일괄 승인`** 을 누르면 배지가 사라집니다.
**내용은 아무것도 바뀌지 않습니다.**

`거절` 은 **삭제**이니 주의하세요.

### 수정하러 갔는데 뭘 고쳐야 할지 모르겠어요

**`AI로 수정하기`** 를 쓰세요. 지적 옆에 있습니다.

지적에는 이미 **어느 항목인지(ID)** 가 들어 있습니다. 누르면 그 내용이 그대로
AI 에이전트에게 전달되므로, 표에서 지적된 항목을 눈으로 찾을 필요가 없습니다.

- 개요의 **정합성 검사** 목록
- **각 산출물 화면** 위쪽의 `점검` 묶음 (다섯 화면 모두)

두 곳 모두에 있습니다. 지적이 여러 건이면 **`전부 AI로 수정하기`** 로 한 번에 시키세요.

> 보낸 요청은 대화에 남습니다. 결과가 마음에 안 들면 이어서 말로 고치면 됩니다.
> 직접 고치고 싶으면 옆의 `직접 수정` 으로 가시면 됩니다.

### 정합성 검사 오류가 계속 떠요

각 지적을 누르면 해당 자리로 이동합니다. 자주 나오는 것들:

| 지적 | 해결 |
| --- | --- |
| 화면에 배치되지 않은 기능 | 정보구조도 → 그 화면 → `상세 기능 연결` 에서 체크 |
| 상세 명세가 없는 필수 기능 | 기능명세서에서 그 기능에 상세 기능 추가 |
| 도달할 수 없는 단계 | 유저 플로우에서 그 단계로 들어오는 연결선 추가 |
| 분기가 하나뿐인 조건 | 실패·거절 경로를 추가 |

### 구글 스티치나 Figma 로 바로 넘길 수 있나요

**스티치는 바로 넘길 수 있습니다.** 내보내기 화면의
`자동 — 스티치로 연결하여 바로 만들기` 에서 한 번 연결하시면, 화면을 골라 누르는
것만으로 **사장님 스티치 계정에 실제 디자인이 만들어집니다.** 개수 제한은 없고,
화면 하나에 40초 안팎 걸립니다.

Figma 를 비롯한 나머지 도구는 아래 `수동 — 요청문 복사해 붙여 넣기` 카드에서
**요청문을 만들어 드립니다.** 화면 이름·기능·역할·와이어프레임의 구성 항목·기획
메모를 도구가 알아듣는 문장으로 조립해 두므로, 복사해서 붙여 넣기만 하면 됩니다. Figma 는 화면별 `SVG` 를 받아 캔버스에 끌어다
놓으면 편집 가능한 레이어로 들어갑니다.

> 연결할 때 붙여 넣은 값은 **암호화해 보관하고 화면으로 다시 내보내지 않습니다.**
> `연결 해제` 를 누르면 지워집니다.

결과가 얕게 나오면 와이어프레임의 **구성 항목**을 확인해 보세요.
`콘텐츠 영역` 처럼 두루뭉술하게 적혀 있으면 도구가 아무 말이나 채웁니다.

### 표가 화면 밖으로 넘쳐요

넓은 표는 좌우로 스크롤됩니다. 표 위에 커서를 두고 좌우로 밀어 보세요.

## 내보내기

### 엑셀에서 한글이 깨져요

깨지지 않도록 처리되어 있습니다. 파일을 두 번 눌러서 열어 보세요.
그래도 깨지면 엑셀에서 `데이터 → 텍스트/CSV 가져오기` 로 열고 인코딩을 `UTF-8` 로 지정하세요.

### 공유 링크가 너무 길어요

기획서 내용이 링크 안에 통째로 담기기 때문입니다. 내용이 많으면 링크도 길어집니다.

경고가 뜰 정도로 길면 **플랜 JSON 파일**로 전달하세요.
받는 사람이 홈에서 `플랜 가져오기` 로 열면 됩니다.

### PDF로 저장하고 싶어요

내보내기 화면에서 **`문서 보기`** 를 켜고 **`인쇄`** 를 누른 뒤,
인쇄 창에서 프린터 대신 **`PDF로 저장`** 을 고르세요.

## 그 외

### 휴대폰에서도 쓸 수 있나요

됩니다. 왼쪽 메뉴가 화면 아래 탭으로 바뀝니다.
다만 마인드맵이나 와이어프레임 편집처럼 넓은 화면이 필요한 작업은
**컴퓨터에서 하시는 편이 훨씬 편합니다.**

### 내가 쓴 내용이 어디로 가나요

- 기획서는 **내 계정에만** 저장되고, 다른 사용자는 볼 수 없습니다.
- **AI로 생성할 때만** 기획서 내용이 AI 서비스로 전달됩니다.
- 공유 링크는 **서버를 거치지 않습니다.** 내용이 링크 안에 담겨 전달됩니다.

### 여기에 없는 문제입니다

관리자에게 문의해 주세요. 이때 아래를 함께 알려 주시면 훨씬 빨리 해결됩니다.

- 어느 화면에서 무엇을 눌렀을 때인지
- 화면에 나온 메시지 (있다면 그대로)
- 상단이 `저장됨` 이었는지 `저장 안 됨` 이었는지
