# 3. AI 공급자와 크레딧

## 세 가지 모드

| | DeepSeek | Anthropic | 내장 생성기 |
| --- | --- | --- | --- |
| 조건 | `DEEPSEEK_API_KEY` 설정 | `ANTHROPIC_API_KEY` 설정 | 키 없음 |
| 산출물 생성 | 모델이 생성 | 모델이 생성 | 규칙 기반 템플릿 |
| AI 에이전트 채팅 | 문서를 실제로 수정 | 문서를 실제로 수정 | 문서 현황 요약만 |
| JSON 형식 강제 | JSON 모드 + 프롬프트 내 스키마 | 구조화 출력 | 해당 없음 |
| 그 외 모든 기능 | 동일 | 동일 | 동일 |

**키가 없어도 앱은 완전히 동작합니다.** 편집·검증·내보내기·공유는 모두 같습니다.

## 공급자 선택 규칙

`AI_PROVIDER` 를 지정하지 않으면 아래 순서로 자동 선택합니다.

```
AI_PROVIDER 지정  →  DEEPSEEK_API_KEY  →  ANTHROPIC_API_KEY  →  내장 생성기
```

`AI_PROVIDER=local` 로 두면 키가 있어도 내장 생성기를 씁니다. 오프라인 작업이나
비용 없이 구조만 잡아볼 때 유용합니다.

## 환경변수 전체 목록

### DeepSeek

| 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | — | [platform.deepseek.com](https://platform.deepseek.com) 에서 발급 |

| 변수 | 값 | 설명 |

| `AI_PROVIDER` | `deepseek` \| `anthropic` \| `local` | 공급자 강제 지정 |

## 내장 생성기가 하는 일

아이디어 문장에서 도메인을 추정해 그에 맞는 산출물 템플릿을 조립합니다.

| 도메인 | 인식 키워드 예시 |
| --- | --- |
| 커머스 | 쇼핑, 상품, 판매, 마켓, 주문, 결제 |
| 커뮤니티 | 커뮤니티, 게시판, 피드, 댓글, 팔로우 |
| 예약 | 예약, 스케줄, 일정, 클래스, 진료 |
| 교육/학습 | 학습, 강의, 수업, 퀴즈, 코스 |
| 협업/생산성 | 협업, 업무, 프로젝트, 팀, 워크스페이스 |
| 헬스/건강 | 운동, 건강, 식단, 습관, 기록 |
| 금융/가계부 | 가계부, 지출, 자산, 정산, 수입 |
| 일반 | (위에 해당하지 않는 경우) |

여기에 회원가입·프로필·알림·관리자 같은 공통 요구사항이 더해집니다.
결과물 품질은 AI 모드보다 낮지만, 구조와 ID 체계는 완전히 동일하므로
이후 편집·검증·내보내기가 그대로 동작합니다.

## 실패했을 때

모델 호출이 실패해도 작업이 끊기지 않습니다.

- **산출물 생성** — 내장 생성기로 자동 전환하고, 화면에 실패 사유를 알려 줍니다.
- **AI 에이전트 채팅** — 실패 사유와 함께 현재 문서 현황을 정리해 답합니다.

### 자주 나오는 오류 메시지

| 메시지 | 원인과 해결 |
| --- | --- |
| API 키가 올바르지 않습니다 | 키를 다시 확인하세요. 앞뒤 공백이 섞였을 수 있습니다 |
| 계정의 잔액이 부족합니다 | 공급자 콘솔에서 충전하세요 |
| 모델 '…' 을(를) 찾을 수 없습니다 | `npm run check:ai` 로 사용 가능한 모델 목록을 확인해 `DEEPSEEK_MODEL` 을 바꾸세요 |
| 요청이 한도를 초과했습니다 | 잠시 후 다시 시도하세요 |
| 응답이 출력 한도에서 잘렸습니다 | `DEEPSEEK_MAX_TOKENS` 를 올리거나 생성 범위를 좁히세요 |
| 응답을 JSON 으로 해석하지 못했습니다 | 모델이 형식을 벗어난 경우입니다. 다시 시도하면 대개 해결됩니다 |
| Host not in allowlist | 사내 프록시·방화벽이 API 도메인을 막고 있습니다 |

## 크레딧

산출물을 만들 때마다 차감되고 **매일 자동 충전**됩니다.

| 작업 | 소모 크레딧 |
| --- | --- |
| 프로덕트 요구사항 | 3 |
| 기능명세서 | 5 |
| 정보구조도 | 4 |
| 유저 플로우 | 3 |
| 와이어프레임 | 5 |
| AI 에이전트 메시지 1건 | 1 |

전체 자동 생성 1회 = 20 크레딧입니다.

현재 하루 한도는 **200 (임시)** 입니다. 화면의 `(임시)` 표기는 정식 요금제를 붙이기 전
임시로 열어 둔 한도라는 뜻입니다.

한도를 바꾸려면 `src/lib/store.ts` 의 `DAILY_CREDIT_LIMIT` 을 수정하세요.
그 아래 `CREDIT_POLICY_VERSION` 도 함께 올리면 이미 저장된 잔량이 새 한도로 즉시 갱신됩니다.
올리지 않으면 기존 사용자는 다음 날 충전 전까지 옛 잔량을 그대로 씁니다.

## 데이터가 어디로 가는가

- **문서는 브라우저 localStorage 에만 저장됩니다.** 서버 데이터베이스가 없습니다.
- **AI 생성을 요청할 때만** 현재 플랜 내용이 서버로 전송되고, 서버가 공급자 API 로 전달합니다.
- **API 키는 서버에만 있습니다.** 브라우저로 내려가지 않습니다.
- 기기를 옮기려면 플랜 JSON 을 내보내고 다른 기기에서 가져오기 하세요.
