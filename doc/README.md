# UniBoard 사용설명서

서비스 아이디어 한 줄을 넣으면 **기획서 한 세트**를 만들어 드립니다.
만들어진 문서는 화면에서 바로 고칠 수 있고, 개발팀이나 외주 업체에 그대로 넘길 수 있는
형태로 내보냅니다.

## 무엇을 만들어 주나요

| 문서 | 이런 걸 담습니다 |
| --- | --- |
| **프로덕트 요구사항** | 이 서비스가 무엇이고, 누구를 위한 것이고, 어디까지 만들 것인가 |
| **기능명세서** | 필요한 기능을 빠짐없이 적고, 각 기능이 화면에서 어떻게 동작하는지 |
| **정보구조도** | 서비스에 어떤 화면들이 있고 어떻게 이어지는지 |
| **유저 플로우** | 사용자가 화면을 어떤 순서로 오가는지 |
| **와이어프레임** | 각 화면에 무엇이 어디에 놓이는지 |

이 다섯 가지가 **서로 연결되어** 있습니다. 기능 하나를 고치면 그 기능이 어느 화면에
들어가는지, 어느 흐름에 걸려 있는지가 함께 따라옵니다. 그래서 "만들기로 해 놓고 화면에는
없는 기능" 같은 구멍을 UniBoard 가 대신 찾아 줍니다.

---

## 5분 만에 첫 기획서 만들기

1. 로그인합니다.
2. 홈에서 **`＋ 기획하기`** 를 누릅니다.
3. **서비스명**과 **아이디어** 두 줄만 적습니다. 나머지는 비워도 됩니다.
4. **`플랜 만들기`** → 개요 화면이 열립니다.
5. **`전체 자동 생성`** 을 누르고 기다립니다.

다섯 개 문서가 순서대로 만들어집니다. 다 되면 왼쪽 메뉴에서 하나씩 열어 보고,
마음에 안 드는 부분만 고치면 됩니다.

> 처음이라 뭘 적어야 할지 모르겠다면, 아이디어 칸 아래의 **예시 칩**을 눌러 보세요.
> 그대로 만들어 보면서 감을 잡을 수 있습니다.

## 알아 두면 좋은 것 세 가지

**저장 버튼이 없습니다.** 고치는 즉시 저장됩니다. 입력칸에서 커서를 빼면 그 순간
반영되고, 잠시 뒤 계정에도 올라갑니다.

**AI가 만든 것은 초안입니다.** 그대로 쓰지 마시고 꼭 읽어 보세요. AI가 새로 만든 항목에는
`신규` 배지가 붙어 있어서, 확인한 것과 아직 안 본 것을 구분할 수 있습니다.

**되돌리기가 필요하면 미리 저장해 두세요.** 크게 손보기 전에 개요 화면에서
`현재 상태 저장` 을 눌러 두면 언제든 그 시점으로 돌아갈 수 있습니다.
