# UniONE FastPlanner 설명서

서비스 아이디어 한 줄에서 **PRD → 기능명세서 → 정보구조도 → 유저 플로우 → 와이어프레임**까지
만들고, 서로 연결하고, 정합성을 검증해 개발팀에 넘기는 AI 기획 에디터입니다.

이 폴더는 앱의 전체 설명서입니다. 순서대로 읽으면 설치부터 확장까지 이어집니다.

## 이 문서를 웹에서 보기

지금은 마크다운 파일입니다. 앱 안에서 `/docs` 경로로 읽을 수 있게 만들 수 있으며,
그때 쓸 목차 정보는 [`manifest.json`](./manifest.json) 에 미리 정리해 두었습니다.

필요할 때 "설명서를 웹에서 볼 수 있게 해줘" 라고 요청하시면 됩니다.

## 한눈에 보는 흐름

```
아이디어 입력
   ↓  기획하기 위저드 (3단계)
플랜 생성
   ↓  전체 자동 생성 또는 단계별 AI 생성
① 프로덕트 요구사항 (PRD)   제품의 목표·타겟·범위
   ↓
② 기능명세서 (FS)           요구사항 → 기능 → 상세명세
   ↓
③ 정보구조도 (IA)           화면 계층 + 기능 배치
   ↓
④ 유저 플로우               화면을 오가는 경로
   ↓
⑤ 와이어프레임              화면별 블록 구성
   ↓
정합성 검사 → 편집 → 내보내기
```
