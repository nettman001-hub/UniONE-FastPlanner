# 4. AI 공급자 설정

## 세 가지 모드

| | DeepSeek | Anthropic | 내장 생성기 |
| --- | --- | --- | --- |
| 조건 | `DEEPSEEK_API_KEY` 설정 | `ANTHROPIC_API_KEY` 설정 | 키 없음 |
| 산출물 생성 | 모델이 생성 | 모델이 생성 | 규칙 기반 템플릿 |
| AI 에이전트 채팅 | 문서를 실제로 수정 | 문서를 실제로 수정 | 문서 현황 요약만 |
| JSON 형식 강제 | JSON 모드 + 프롬프트 내 스키마 | 구조화 출력 | 해당 없음 |
| 그 외 모든 기능 | 동일 | 동일 | 동일 |

**키가 없어도 앱은 완전히 동작합니다.** 편집·검증·내보내기·공유는 모두 같습니다.

## 공급자 선택 규칙

`AI_PROVIDER` 를 지정하지 않으면 아래 순서로 자동 선택합니다.

```
AI_PROVIDER 지정  →  DEEPSEEK_API_KEY  →  ANTHROPIC_API_KEY  →  내장 생성기
```

`AI_PROVIDER=local` 로 두면 키가 있어도 내장 생성기를 씁니다. 오프라인 작업이나
비용 없이 구조만 잡아볼 때 유용합니다.

## 어디서 정하나 — 관리자 화면 vs 환경변수

**관리자 → AI 설정**에서 공급자·엔드포인트·등급별 모델·추론 강도·출력 상한을
고칠 수 있습니다. 저장하면 **다음 생성부터 바로** 적용됩니다 — 다시 배포할
필요가 없습니다.

```
관리자 화면에 적은 값  >  환경변수  >  코드 기본값
```

**빈 칸은 "정하지 않음"** 입니다. 그 자리는 환경변수를 쓰고, 환경변수도 없으면
코드 기본값을 씁니다. `모두 비우기` 를 누르면 이 기능이 생기기 전과 정확히 같은
동작으로 돌아갑니다.

화면 위쪽에 **지금 실제로 도는 값**을 함께 보여 줍니다. 빈 칸이 환경변수를
따르기 때문에, 적어 둔 것만 보면 무엇이 도는지 알 수 없어서입니다.

### API 키

키도 화면에서 넣습니다. **넣은 값은 잠가서 보관하고 다시 보여 주지 않습니다** —
꼬리표(`••••7890`)와 어디서 온 키인지만 보입니다.

```
화면에서 넣은 키  >  환경변수
```

비워 두고 저장하면 건드리지 않고, `키 지우기` 를 누르면 환경변수로 되돌아갑니다.
자세한 것은 [관리자 화면](./08-admin.md) 을 보세요.

저장은 `app_settings` 표의 **줄 하나**에 들어갑니다. 캐시하지 않습니다 —
서버리스는 인스턴스가 여럿이라 캐시를 두면 인스턴스마다 다른 설정으로 도는
시간이 생깁니다.

## 엔진 등급 — 기본 / 고급

사용자는 **설정 → 만들기**에서 둘 중 하나를 고릅니다. 계정마다 하나이고,
그 계정으로 만드는 모든 플랜에 적용됩니다.

| 화면에 보이는 것 | 실제로 부르는 것 |
| --- | --- |
| `기본 엔진` | `DEEPSEEK_MODEL_BASIC` |
| `고급 엔진` | `DEEPSEEK_MODEL_ADVANCED` |

**모델 이름은 화면에 절대 나가지 않습니다.** 브라우저로 가는 파일
(`lib/ai/engines.ts`)에는 등급 이름만 있고, 어떤 모델인지는 서버만 아는 값
(`lib/ai/provider.ts`)입니다. 알아도 사용자가 할 수 있는 일이 없는데 서비스
내부 구성만 드러나고, 모델을 갈아 끼울 때마다 화면·문서를 따라 고쳐야 합니다.

고른 값은 **서버가 계정에서 읽습니다.** 브라우저가 보내게 하면 요청을 손봐서
비싼 쪽을 마음대로 부를 수 있습니다.

**고급 엔진은 크레딧이 두 배입니다.** 더 큰 모델이 더 오래 생각하는 만큼 실제로
드는 값이 다릅니다. 배수는 `lib/credits.ts` 의 `ENGINE_CREDIT_MULTIPLIER` 에
있고, **화면과 서버가 같은 함수(`costOfArtifact`)를 씁니다** — 표시하는 쪽과 깎는
쪽이 갈리면 "3 크레딧이라더니 6 이 나갔다" 가 됩니다.

| | 기본 | 고급 |
| --- | --- | --- |
| 프로덕트 요구사항 | 3 | 6 |
| 기능명세서 | 5 | 10 |
| 전체 자동 생성 | 20 | 40 |

### 추론 강도

**두 등급 모두 가장 깊게 생각하도록 요청합니다.** 등급 차이는 모델 자체의
크기에서 나오지, 생각을 덜 하게 해서 내는 것이 아닙니다.

문제는 이 엔드포인트가 `reasoning_effort` 를 **어느 단계까지 받는지 알 수 없다**는
것입니다. 모르는 값을 보내면 400 이 떨어지고 생성이 실패합니다. 그래서 사다리로
둡니다.

```
max → xhigh → high → (파라미터 없이)
```

위에서부터 보내다가 **그 값 때문에** 거부당하면 한 칸 내려와 같은 요청을 다시
보냅니다. 다 떨어지면 파라미터를 빼고 부릅니다. 어디까지 되는지는 기억해 두어
서버가 사는 동안 같은 헛걸음을 반복하지 않습니다.

어느 단계까지 받는지 확인하려면:

```bash
npm run check:ai
```

```
▶ 추론 강도 (reasoning_effort) … ok — 'max' 로 동작합니다 (가장 높은 단계)
```

확실히 아는 값이 있으면 **관리자 → AI 설정**에서 못 박으면 됩니다
(환경변수 `DEEPSEEK_REASONING_EFFORT` 로도 됩니다). `보내지 않기` 도 고를 수 있습니다.

## 내장 생성기가 하는 일

아이디어 문장에서 도메인을 추정해 그에 맞는 산출물 템플릿을 조립합니다.

| 도메인 | 인식 키워드 예시 |
| --- | --- |
| 커머스 | 쇼핑, 상품, 판매, 마켓, 주문, 결제 |
| 커뮤니티 | 커뮤니티, 게시판, 피드, 댓글, 팔로우 |
| 예약 | 예약, 스케줄, 일정, 클래스, 진료 |
| 교육/학습 | 학습, 강의, 수업, 퀴즈, 코스 |
| 협업/생산성 | 협업, 업무, 프로젝트, 팀, 워크스페이스 |
| 헬스/건강 | 운동, 건강, 식단, 습관, 기록 |
| 금융/가계부 | 가계부, 지출, 자산, 정산, 수입 |
| 일반 | (위에 해당하지 않는 경우) |

여기에 회원가입·프로필·알림·관리자 같은 공통 요구사항이 더해집니다.
결과물 품질은 AI 모드보다 낮지만, 구조와 ID 체계는 완전히 동일하므로
이후 편집·검증·내보내기가 그대로 동작합니다.

## 실패했을 때

모델 호출이 실패해도 작업이 끊기지 않습니다.

- **산출물 생성** — 내장 생성기로 자동 전환하고, 화면에 실패 사유를 알려 줍니다.
- **AI 에이전트 채팅** — 실패 사유와 함께 현재 문서 현황을 정리해 답합니다.

### 자주 나오는 오류 메시지

| 메시지 | 원인과 해결 |
| --- | --- |
| API 키가 올바르지 않습니다 | 키를 다시 확인하세요. 앞뒤 공백이 섞였을 수 있습니다 |
| 계정의 잔액이 부족합니다 | 공급자 콘솔에서 충전하세요 |
| 모델 '…' 을(를) 찾을 수 없습니다 | `npm run check:ai` 로 사용 가능한 모델 목록을 확인해 `DEEPSEEK_MODEL_BASIC` · `DEEPSEEK_MODEL_ADVANCED` 를 바꾸세요 |
| 요청이 한도를 초과했습니다 | 잠시 후 다시 시도하세요 |
| 응답이 출력 한도에서 잘렸습니다 | `DEEPSEEK_MAX_TOKENS` 를 올리거나 생성 범위를 좁히세요 |
| 응답을 JSON 으로 해석하지 못했습니다 | 모델이 형식을 벗어난 경우입니다. 다시 시도하면 대개 해결됩니다 |
| Host not in allowlist | 사내 프록시·방화벽이 API 도메인을 막고 있습니다 |

## 크레딧

산출물을 만들 때마다 차감되고 **매일 자동 충전**됩니다.

| 작업 | 소모 크레딧 |
| --- | --- |
| 프로덕트 요구사항 | 3 |
| 기능명세서 | 5 |
| 정보구조도 | 4 |
| 유저 플로우 | 3 |
| 와이어프레임 | 5 |
| AI 에이전트 메시지 1건 | 1 |

전체 자동 생성 1회 = 20 크레딧입니다. 위 표는 **기본 엔진** 기준이고,
**고급 엔진은 두 배**입니다(`ENGINE_CREDIT_MULTIPLIER`).

현재 하루 한도는 **200 (임시)** 입니다. 화면의 `(임시)` 표기는 정식 요금제를 붙이기 전
임시로 열어 둔 한도라는 뜻입니다.

한도를 바꾸려면 `src/lib/store.ts` 의 `DAILY_CREDIT_LIMIT` 을 수정하세요.
그 아래 `CREDIT_POLICY_VERSION` 도 함께 올리면 이미 저장된 잔량이 새 한도로 즉시 갱신됩니다.
올리지 않으면 기존 사용자는 다음 날 충전 전까지 옛 잔량을 그대로 씁니다.

## 데이터가 어디로 가는가

- **문서는 브라우저 localStorage 에만 저장됩니다.** 서버 데이터베이스가 없습니다.
- **AI 생성을 요청할 때만** 현재 플랜 내용이 서버로 전송되고, 서버가 공급자 API 로 전달합니다.
- **API 키는 서버에만 있습니다.** 브라우저로 내려가지 않습니다.
- 기기를 옮기려면 플랜 JSON 을 내보내고 다른 기기에서 가져오기 하세요.
