# 관리자 화면

**`/admin`** 입니다. 가입자·사용량을 보고, 크레딧을 되돌려 주고, 지금 무엇이
물려 있는지 확인합니다.

---

## 켜는 법

환경변수 하나입니다.

```
ADMIN_EMAILS=nettman001@gmail.com
```

쉼표로 여럿 적을 수 있습니다. 대소문자와 앞뒤 공백은 알아서 맞춥니다.

| 어디에 | |
| --- | --- |
| 로컬 | `.env.local` |
| 배포 | Vercel → Settings → Environment Variables → 넣고 **다시 배포** |

넣으신 뒤 그 계정으로 로그인하면 오른쪽 위 이름 메뉴에 **`관리자`** 가 생깁니다.

> **비어 있으면 아무도 관리자가 아닙니다.** 비었을 때 전부 허용으로 열리는 실수가
> 흔한데, 여기서는 반대로 닫힙니다. 관리자 화면을 못 보는 것은 불편할 뿐이지만
> 아무나 보는 것은 사고입니다.

### 왜 데이터베이스가 아니라 환경변수인가

`users` 표에 역할 칸을 두지 않았습니다. 환경변수로 두면 **데이터베이스가 통째로
새어도 관리자 권한까지 새지는 않습니다** — 표를 고칠 수 있는 사람이 스스로를
관리자로 만들 수 없습니다. 바꾸려면 배포를 해야 합니다.

관리자를 여럿 두거나 화면에서 임명해야 할 때가 오면 그때 표로 옮깁니다.

---

## 안 보이게 하는 방식

관리자가 아니면 **404** 입니다. 403(권한 없음)이 아닙니다.

403 은 "여기 뭔가 있다" 를 알려 주는 셈입니다. 있는지조차 모르는 편이 낫습니다.

그리고 **화면만 감추지 않습니다.** `/api/admin` 도 404 를 줍니다. 화면에서만
감추면 주소를 아는 사람은 그냥 들어옵니다.

---

## 화면

### 대시보드 `/admin`

| | |
| --- | --- |
| 계정 | 전체 가입자 · 오늘 가입 · 최근 7일 활동 |
| 오늘 | 만든 횟수 · 쓴 크레딧 · 전체 플랜 |
| 쓰고 있는 기능 | 스티치를 이어 둔 계정 수 · 기획 스킬을 켜 둔 계정 수 |

AI 가 실패해 기본 생성기로 대신한 것은 크레딧이 들지 않으므로 `오늘` 에 안 잡힙니다.

### 사용자 `/admin/users`

이메일·이름으로 찾고, 가입일·플랜 수·오늘 쓴 양·마지막 활동을 봅니다.

> **플랜 숫자를 누르면 목록이, 목록에서 제목을 누르면 본문이 열립니다.**
> 본문은 고른 하나만, 열 때만 가져옵니다. 연 것은 서버 로그에 남습니다.

**`크레딧`** 을 누르면 되돌려 줍니다. 쓴 기록을 지우지 않고 **상쇄하는 줄을 하나 더
적습니다**(`kind = grant`, 음수). 지우면 무슨 일이 있었는지가 사라져 나중에
되짚을 수 없습니다.

한 번에 1~1000 까지입니다. 준 기록은 서버 로그에도 남습니다.

### AI 설정

공급자·엔드포인트·등급별 모델·추론 강도·출력 상한을 여기서 바꿉니다.
**저장하면 다음 생성부터 적용됩니다 — 다시 배포할 필요가 없습니다.**

| 칸 | 비워 두면 |
| --- | --- |
| 공급자 | `AI_PROVIDER`, 없으면 키가 있는 쪽 순서대로 |
| 엔드포인트 | `DEEPSEEK_BASE_URL`, 없으면 공급자 기본 주소 |
| 기본 / 고급 엔진 모델 | `DEEPSEEK_MODEL_BASIC` · `DEEPSEEK_MODEL_ADVANCED` |
| 추론 강도 | 자동 — 되는 만큼 가장 높게 |
| 출력 상한 | 앱 전체 고정 `384000` 토큰 |

화면 위쪽에 **지금 실제로 도는 값**이 함께 나옵니다. 빈 칸은 환경변수를 따르므로
적어 둔 것만 봐서는 무엇이 도는지 알 수 없습니다.

### API 키

**키도 여기서 넣습니다.** 다만 넣은 값을 다시 보여 주지는 않습니다.

- 저장할 때 **잠급니다** — `AUTH_SECRET` 에서 뽑은 열쇠로 AES-256-GCM.
- 화면에는 꼬리표(`••••7890`)와 **어디서 온 키인지**만 내려옵니다. 키가 브라우저로
  내려가면 관리자 화면을 여는 것만으로 새어 나가기 때문입니다.
- 칸을 **비워 두고 저장하면 건드리지 않습니다.** 모델 하나 바꿀 때마다 키를 다시
  치게 하면 안 됩니다. 지우려면 `키 지우기` 를 따로 누릅니다.
- 지우면 **환경변수의 키로 되돌아갑니다.**

```
화면에서 넣은 키  >  환경변수(DEEPSEEK_API_KEY 등)
```

> `AUTH_SECRET` 을 바꾸면 넣어 둔 키를 못 풀게 되어 환경변수로 되돌아갑니다.
> 그때는 화면에서 다시 넣으시면 됩니다.

고른 공급자의 키가 아예 없으면 붉은 글씨로 알려 주고, 그 상태에서는 내장
생성기로 만듭니다.

### 출력 상한

받아 주는 범위는 256 ~ 1,000,000 입니다. **진짜 상한은 공급자가 정합니다** —
DeepSeek 은 386,000 입니다. 모델이 받아 주는 값보다 크게 넣으면 매 호출이 400 으로
떨어지고 내장 생성기로 대체됩니다.

> 상한을 올리면 산출물마다 요청하는 분량도 같은 비율로 함께 올라갑니다
> (`lib/jobs/queue.ts` 의 `maxTokensFor`). 생성 라우트는 300초 제한이 있으니,
> 너무 크게 잡으면 다 만들기 전에 끊길 수 있습니다.

> 모델 이름이 틀리면 매 호출이 실패하고 내장 생성기로 대체됩니다. 문서는
> 만들어지지만 결이 달라지므로, 저장 뒤에 하나 만들어 확인해 보세요.

## 사용자 — 플랜 보기

**플랜 숫자를 누르면** 그 사용자의 플랜 목록이 열립니다.

| 목록에 보이는 것 |
| --- |
| 제목, 만든/수정한 날 |
| 다섯 단계 중 무엇이 만들어졌는지 |
| 요구사항·기능·화면·플로우·와이어프레임 **개수** |

세는 일은 데이터베이스에서 합니다(`jsonb_array_length`) — 본문을 서버로 끌어와
세면 그 순간 메모리에 남의 기획서가 통째로 올라옵니다.

### 본문 보기

**목록에서 제목을 누르면** 그 기획서의 본문이 같은 창에 열립니다. 내보내기와
같은 함수(`lib/export.ts` 의 `toMarkdown`)로 조립하므로, 사용자가 내려받는 것과
관리자가 보는 것이 같습니다.

세 가지를 지킵니다.

| | 왜 |
| --- | --- |
| **목록에는 본문을 안 싣는다** | 목록을 여는 것만으로 그 사람의 기획서를 전부 받게 됩니다. 본문은 고른 하나만, 누를 때만 갑니다 |
| **주인과 짝이 맞아야 준다** | `user_id` 와 `id` 를 함께 봅니다. 플랜 id 만으로 열리면 화면에서 고르는 의미가 없습니다 |
| **연 것은 기록에 남는다** | 누가·누구의·어느 플랜을 열었는지 서버 로그에 남깁니다. 본문 자체는 안 남깁니다 |

```
[admin] someone@example.com 이(가) usr_… 의 플랜 plan_… 본문을 열었습니다.
```

없는 플랜과 남의 플랜은 **똑같이 404** 입니다. 404 와 403 이 갈리면 그 차이만으로
"이 id 는 있다" 가 새어 나갑니다.

> 기록은 지금 **서버 로그에만** 남습니다. 배포처의 로그 보관 기간이 지나면
> 사라집니다. 오래 남겨야 하면 표를 하나 두고 append-only 로 적어야 합니다.

## 점검 `/admin/health`

| | |
| --- | --- |
| 저장 | Postgres 인지 임시인지 · `AUTH_SECRET` 유무 |
| AI | 켜짐/꺼짐 · **공급자와 모델** · 출력 상한 |
| 그 밖에 | 가입 정책 · 스티치 주소 |

**공급자와 모델은 이 화면에서만 보입니다.** 사용자에게 감추는 규칙은 일반 화면에
대한 것이고, 관리자는 무엇이 도는지 알아야 고칠 수 있습니다.

## 아직 없는 것

| | 왜 |
| --- | --- |
| 계정 정지·삭제 | `users` 에 상태 칸이 필요합니다 |
| 가입 정책 바꾸기 | 지금은 환경변수(`SIGNUP_CODE`·`ALLOW_SIGNUP`)라 화면에서 못 바꿉니다. 설정 표가 하나 필요합니다 |
| 단계별 AI 모델 지정 | 요금과 약관을 먼저 정해야 합니다 |
| 플랜 목록·검색 | 통계로 충분한지 먼저 보고 정합니다 |

## 검사

```
node admin.mjs      # ADMIN_EMAILS 에 검사용 계정을 넣은 서버에 대고
```

**누가 못 들어오는가**를 먼저 봅니다 — 보통 사람은 화면도 API 도 404, 차림표에도
안 보임. 그다음 관리자로 들어가 숫자와 크레딧 되돌리기를 봅니다.

`ADMIN_EMAILS` 를 아예 안 준 서버에도 돌려 보십시오. 관리자로 지정한 계정마저
못 들어가야 맞습니다.
