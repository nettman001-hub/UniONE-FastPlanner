# 6. AI 에이전트

상단의 **`AI 에이전트`** 를 누르면 오른쪽에 대화창이 열립니다.

직접 칸을 채우는 대신 **말로 시킬 수 있습니다.** 에이전트는 지금 기획서 전체를 읽고
있어서, "여기" 나 "이 기능" 같은 말도 알아듣습니다.

---

## 두 가지 쓰임

### 1. 물어보기

```
지금 빠진 게 뭐야?
P0 기능이 몇 개야?
결제 관련 기능은 어디에 있어?
```

문서를 읽고 답만 합니다. 아무것도 바꾸지 않습니다.

### 2. 고쳐 달라고 하기

```
회원 탈퇴 기능을 추가해줘
알림 관련 요구사항의 우선순위를 P0으로 올려줘
검색 화면 와이어프레임에 필터를 넣어줘
```

문서를 실제로 고칩니다. 고쳤다면 답변 아래에 **"문서 반영됨"** 과 **무엇을 바꿨는지**
목록이 나옵니다.

---

## 특정 항목을 콕 집어 시키기

입력창 위의 드롭다운에서 **요구사항·기능·화면을 하나 고르면** 그 항목을 기준으로 답합니다.

고른 항목이 입력창 위에 표시되므로, 이렇게만 써도 알아듣습니다.

```
이거 예외 처리 좀 채워줘
여기에 인수 조건 3개 추가해줘
```

---

## 쓰는 법

| 항목 | 내용 |
| --- | --- |
| 전송 | **⌘/Ctrl + Enter** |
| 비용 | 메시지 1건당 **1 크레딧** (답을 받았을 때만 차감됩니다) |
| 크레딧이 없으면 | 입력창이 잠깁니다 |

---

## 시켜 놓고 다른 문서를 봐도 됩니다

에이전트에게 요청해 놓고 **왼쪽 메뉴로 다른 문서를 보러 가도 됩니다.**
패널은 계속 열려 있고, 요청도 그대로 진행됩니다.

- 패널을 **닫아 두어도** 상단 `AI 에이전트` 버튼이 돌아가는 표시로 진행 중임을 알려 줍니다.
  다시 열면 진행 상황이 그대로 보입니다.
- **새로고침해도 패널은 열린 채로** 시작합니다.

### 답변을 못 받았을 때

새로고침하거나 인터넷이 끊기면 요청이 중단됩니다. 이때는 대화에 이렇게 남습니다.

> 답변을 받지 못했습니다. 요청이 중단되었거나 연결이 끊겼습니다.
> `↻ 다시 보내기`

**`다시 보내기`** 를 누르면 같은 질문을 그대로 다시 보냅니다. 질문을 또 적을 필요가 없고,
**크레딧도 차감되지 않은 상태**입니다 — 답을 받았을 때만 빠져나가기 때문입니다.

---

## 잘 쓰는 요령

**한 번에 하나씩 시키세요.** "요구사항 추가하고 우선순위도 바꾸고 화면도 연결해줘" 보다
세 번 나눠 시키는 편이 정확합니다.

**구체적으로 적으세요.**

| ❌ | ✅ |
| --- | --- |
| 기능 좀 더 넣어줘 | 관리자가 신고를 처리하는 기능을 요구사항으로 추가해줘 |
| 이거 이상해 | 이 상세 기능의 기본 흐름이 두 단계뿐인데 더 자세히 나눠줘 |

**바꾼 내용은 꼭 확인하세요.** "문서 반영됨" 아래 목록을 읽고, 해당 문서를 열어
의도대로 됐는지 봅니다. 아니면 되돌리면 됩니다.

> 크게 시키기 전에 개요 화면에서 **`현재 상태 저장`** 을 눌러 두세요.
> 결과가 마음에 안 들면 그 시점으로 복원할 수 있습니다.

---

## 답변이 이상할 때

**"…에 실패했습니다" 와 함께 현재 문서 현황이 나온다면** AI 호출이 실패한 것입니다.
잠시 후 다시 시도해 보세요. 계속 그러면 관리자에게 알려 주세요.

**문서를 안 고치고 설명만 한다면** 요청이 모호했을 가능성이 큽니다.
무엇을, 어디에, 어떻게 바꿀지 더 구체적으로 다시 적어 보세요.
