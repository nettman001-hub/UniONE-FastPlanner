# 2. 플랜 관리

기획서 하나를 **플랜**이라고 부릅니다. 서비스 하나당 플랜 하나라고 생각하시면 됩니다.

---

## 새로 만들기

홈에서 **`＋ 기획하기`** 를 누르면 3단계 창이 열립니다.

### 1단계 — 무엇을 만드나요

| 칸 | 필수 | 예시 |
| --- | --- | --- |
| **서비스명** | ✅ | `산책메이트` |
| 한 줄 소개 | | `동네 반려견 산책 친구를 찾아주는 앱` |
| **서비스 아이디어** | ✅ | 어떤 문제를 어떻게 풀어 주는지 |

**아이디어를 자세히 적을수록 결과가 좋아집니다.** 한 문장보다는 세 문장이 낫습니다.
누가, 어떤 불편을 겪고 있고, 이 서비스가 그걸 어떻게 없애 주는지를 적어 보세요.

> 아래 **예시 칩**을 누르면 샘플 문장이 채워집니다. 어떻게 쓰는지 감이 안 잡힐 때 참고하세요.

### 2단계 — 누구를 위한 건가요

| 칸 | 예시 |
| --- | --- |
| 타겟 사용자 | `서울에 사는 20~30대 1인 가구 반려인` |
| 기획 목적 | `MVP 범위를 정하고 개발 견적을 받기 위해` |
| 플랫폼 | 웹 / 모바일 앱 / 웹＋앱 / 어드민 |

**비워 두어도 됩니다.** 비우면 AI 가 아이디어를 읽고 알아서 추정합니다.

### 3단계 — 참고 정보 (선택)

| 칸 | 예시 |
| --- | --- |
| 참고 서비스 | `당근마켓, 스트라바` |
| 반드시 포함할 기능 | `위치 기반 매칭, 산책 일지, 신고하기` |

**꼭 들어가야 하는 기능이 있다면 여기에 적으세요.** AI 가 빠뜨리지 않습니다.

마지막의 **`만들면서 PRD도 바로 생성하기`** 체크를 켜 두면, 플랜을 만들자마자
프로덕트 요구사항이 자동으로 만들어집니다.

---

## 플랜 카드 읽는 법

홈의 카드 하나가 기획서 하나입니다.

```
┌─────────────────────────────┐
│ 산책메이트               ⋮  │  ← 서비스명 / 메뉴
│ 동네 산책 친구를 찾아주는 앱  │  ← 한 줄 소개
│                             │
│ [모바일 앱] [산출물 3/5]      │  ← 플랫폼 / 진행률
│ [PRD✓][기능명세서✓][정보구조도✓]│  ← 만들어진 문서
│ [유저 플로우][와이어프레임]     │     (흐린 것은 아직 안 만듦)
│                             │
│ 요구사항 7 · 기능 21 · 화면 23 │  ← 담긴 내용
│ 최종 수정 2시간 전            │
└─────────────────────────────┘
```

카드를 누르면 그 기획서로 들어갑니다.

### ⋮ 메뉴

| 항목 | 하는 일 |
| --- | --- |
| **이름 변경** | 서비스명을 바꿉니다 |
| **복제** | 똑같은 내용으로 하나 더 만듭니다 |
| **JSON 내보내기** | 파일로 저장합니다 (백업용) |
| **삭제** | 완전히 지웁니다 — **되돌릴 수 없습니다** |

> **복제**는 이럴 때 씁니다. 지금 기획서를 크게 바꿔 보고 싶은데 원본도 남기고 싶을 때,
> 먼저 복제해 두고 사본을 고치세요.

---

## 다른 컴퓨터에서 보기

**같은 계정으로 로그인하면 그대로 따라옵니다.** 따로 하실 일이 없습니다.

집에서 만들고 사무실에서 이어서 작업하거나, 노트북과 데스크톱을 오가며 쓸 수 있습니다.

### 두 곳에서 동시에 고치면요?

**나중에 고친 쪽이 남습니다.** 같은 기획서를 두 컴퓨터에서 동시에 열어 두고 각각
다른 부분을 고치면 마지막 편집만 남을 수 있으니, 한 번에 한 곳에서 작업하시는 편이 안전합니다.

### 한 곳에서 지우면요?

**다른 컴퓨터에서도 사라집니다.** 되살아나지 않습니다.

---

## 파일로 백업하기

계정에 저장되지만, 중요한 기획서는 파일로도 받아 두시면 마음이 편합니다.

**내보내기** → **플랜 JSON** 을 내려받으면 기획서 전체가 파일 하나에 담깁니다.
카드의 `⋮` → `JSON 내보내기` 로도 됩니다.

### 되돌리기

홈의 **`플랜 가져오기`** 를 누르고 그 파일을 고르면 됩니다.
**파일을 화면에 끌어다 놓아도** 됩니다. 여러 개를 한 번에 놓아도 됩니다.

가져온 기획서는 **새 기획서로 추가**됩니다. 기존 것을 덮어쓰지 않습니다.

---

## 로그인 전에 만든 기획서

로그인 기능이 생기기 전에 만들어 둔 기획서가 있다면, 처음 로그인할 때 화면 위에
안내가 뜹니다.

> 로그인 전에 이 브라우저에서 만든 플랜이 **N개** 있습니다.
> `내 계정으로 가져오기`  `버리기`

**`내 계정으로 가져오기`** 를 누르면 계정으로 올라가고, 그때부터 다른 컴퓨터에서도 보입니다.

누르기 전까지는 올라가지 않습니다. 한 컴퓨터를 여러 사람이 나눠 쓰는 경우에
남의 기획서가 내 계정으로 딸려 들어가면 안 되기 때문입니다.

> `버리기` 는 되돌릴 수 없습니다. 헷갈리면 그냥 두세요. 안내는 사라지지 않습니다.

---

## 로그아웃하면 기획서가 안 보여요

**정상입니다.** 기획서는 계정에 있고, 이 컴퓨터에 있던 사본만 지운 것입니다.
**같은 계정으로 다시 로그인하면 그대로 돌아옵니다.**

한 컴퓨터를 여러 사람이 쓸 때 앞사람 기획서가 뒷사람에게 보이지 않게 하려는 것입니다.
